# Security reports

Do not post access tokens, passwords, private logs or exploit data containing user information in public issues. For a sensitive vulnerability, first ask the maintainer for a private contact channel without disclosing exploit details. A private reporting channel has not yet been configured for this repository.

The current alpha is a development build. Support and response-time guarantees are not established. The currently tested platform is Windows x64.

Downloads must retain trusted origins and checksum validation. Renderer code has no Node.js access. Credentials are encrypted using the Windows user account. The public Microsoft Client ID is intentionally distributed and is not a client secret. The built-in diagnostic export excludes accounts, tokens, instance names, local paths and raw logs.
