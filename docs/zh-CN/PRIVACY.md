# 隐私与本地数据

[English](../../PRIVACY.md)

AMBER 不自动上传诊断、原始日志、存档或本地模组文件。按需下载和搜索会联系 Mojang/微软、Modrinth、加载器服务、Adoptium 或 GitHub，相关服务会收到正常网络请求信息。可选的本地模组来源识别只向 Modrinth 发送 SHA-1 哈希，不发送文件内容。

微软授权在微软网页完成，AMBER 不收集微软密码。第三方密码发送到用户填写的 HTTPS 认证地址，不持久保存。令牌使用 系统用户加密保存在 `accounts.json`，公开 Client ID 不是秘密。加密无法抵御以同一 Windows 身份运行的恶意程序。

设置 → 语言与隐私显示存储位置。实例包含游戏/模组日志、存档和配置。移除活动账号后，旧升级备份可能仍保留加密账号数据。本地移除不撤销服务端授权。

AMBER 与 AmberE 分别使用 `%APPDATA%/AMBER` 和 `%APPDATA%/AmberE`。AMBER 在加密账号库中保存官方角色标识、资格时间戳和关联账号引用。AmberE 不提供微软认证，不内置微软 Client ID。两个版本不会自动互相转移账号或游戏数据；第三方密码与令牌均按上述方式处理。

诊断导出采用字段白名单，不含账号、令牌、实例名称、个人路径与原始日志，导出前可预览。错误显示及复制尽量脱敏，但不能保证识别任意模组输出。原始日志及进程参数可能含个人信息，公开前必须检查。

可关闭登录验证码自动复制。AMBER 仍在运行时，到期计时器仅清理仍为该验证码的剪贴板，不影响后来复制的内容。语言包和背景图片只保存在本机，不上传。语言包可改变提示含义，应仅导入可信来源。

卸载保留游戏数据。手动删除前先使用回收站和备份；游戏、安装或恢复运行期间不要清理日志与缓存。

设置提供带确认的程序更新下载和旧升级配置备份清理，不删除活动账号、存档或实例备份。

试用副本和变更恢复快照保存在所选本地游戏库；主动选择时副本会包含存档。配置快照可能保留游戏或模组写入的个人信息，不自动上传，也不包含在推荐模板导出中。模板 JSON 仅包含问卷偏好，分享前仍应检查。全局快捷搜索在本地查找实例和操作，不向服务器发送搜索词。

## 首页模块（1.2.0）

游玩记录保存在本机，默认开启，可在日历设置中关闭、导出或清除。记录包括实例标识、时间和可确认的运行时段，可能包含挂机；并行运行的实例时长分别累加。缺失观测标记为记录不完整，旧启动记录不补造时长。导出文件含实例标识与时间，分享前请检查。

新闻默认手动刷新。开启自动刷新后，仅当模块已加载且页面可见时每 30 分钟至多刷新一次。请求访问 `launchercontent.mojang.com`，综合文章使用系统浏览器打开；正文不自动翻译，不执行远程 HTML。新闻与更新说明缓存在本机。截图浏览只读取本地 PNG，“复制图片”将图片写入系统剪贴板，不上传截图。存储扫描仅缓存本地估算，不自动清理文件。

## 下载连接（1.2.2）

自动选择来源和手动连接诊断会访问 Minecraft 与 BMCLAPI 的公开端点，诊断还会访问 Modrinth 与 Fabric。请求包含普通连接信息（包括 IP 地址和启动器 User-Agent），不发送账号令牌、实例名称或本地路径。自动选择缓存来源十分钟，不获取地理位置。支持的文件可能通过 BMCLAPI 及其公网 CDN 节点下载，第三方服务遵循各自隐私政策。账号认证不会通过下载镜像。复制的诊断摘要只包含服务名称、状态与耗时；下载片段和恢复记录留在本地游戏库。

## 本地整合包导入（1.2.3）

选择的压缩包及导入选项保存在新实例的 `.amber-setup` 目录内，供恢复安装使用。导入器不上传压缩包、内嵌配置或存档。MRPACK 下载会访问其清单中允许的内容来源，游戏、Java 和加载器准备仍访问各自正常来源。导入报告包含相对文件名和整合包元数据；实例备份可能包含这些保留内容，分享前请检查。

## 1.3.0 本地工具

皮肤查询会向账号身份提供方及允许的纹理主机发送角色标识；皮肤缓存在本地。截图、配置、备份、依赖布局和渐变预设不自动上传。配置旁的 .bak 备份可能包含服务器地址或私人数据。

## 文字作品（1.3.1）

配色预设与完整格式作品保存在当前产品的本地浏览器存储中，可能包含用户输入的文字，不自动上传。复制将生成内容写入剪贴板；导出由用户主动保存为文本文件。分享前请检查文字内容。

## 服务端工作区（1.3.2）

服务端世界、设置、控制台日志、内容、恢复副本和 Java 选择保存在选定的本地游戏数据目录。配置及其备份可能包含明文 RCON／管理协议凭据。房间邀请码包含共享密钥，仅在活动房间中保留，请有意识地复制分享。可选 EasyTier 下载会连接 GitHub；配置的发现／中继节点能观察网络地址和流量信息。核心和插件可能自行联网；本功能不会向 AMBER 上传服务端数据。

## 1.3.4

种子地图离线计算，种子与标记保存在本地；读取 level.dat 不上传或修改世界。渐变文字及配色保存在本地。原版目录导入仅将选定游戏数据复制到新实例，排除账号库；元数据和下载使用既有来源，源目录保留。复制的配置与存档可能包含个人信息，分享前请检查。

## 1.3.5 本地身份与平台

离线自定义名称和 PNG 皮肤保存在加密账号记录中。皮肤服务仅监听本机回环地址，为单次游戏身份提供贴图，不执行在线认证，不自动上传皮肤。首次需要从 authlib-injector 官方源下载并校验兼容组件。

Windows 使用系统用户加密，macOS 使用 Keychain，Linux/FreeBSD 需要可用的安全密钥库，拒绝 basic_text 明文回退。默认启动器配置位置分别为 `%APPDATA%/<产品名>`、`~/Library/Application Support/<产品名>`、`$XDG_CONFIG_HOME/<产品名>`（未设置时 `~/.config/<产品名>`）；游戏库位置由用户选择。不要将系统绑定的账号密文当成跨平台凭据。

## 1.3.6 日志分析

分析在本机进行，不调用外部 AI 或上传日志。仅读取选定实例匹配运行时间的有限日志片段，或用户手动选择的日志文件。界面证据经过现有脱敏规则处理，但规则不保证消除全部私人信息，分享前请自行检查。
