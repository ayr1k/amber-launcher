# Beta 1.5 安全检查

[English](../SECURITY-REVIEW.md)

范围：账号存储与 IPC 暴露、错误显示和复制、诊断、响应及文件大小限制、桌面隔离、下载来源及完整性、压缩包与路径防护、恢复事务、自定义语言包和发布内容。这是针对性的工程检查，不是独立渗透测试或安全认证。

## 已验证的改动

- 向界面返回错误和运行日志尾部前，去除已知内存凭据及常见令牌、邮箱、用户目录模式；复制时再次脱敏，不重写原始游戏/模组日志。
- 账号库拒绝非普通文件与链接，限制 2 MB；认证和更新响应在流式读取时分别限制 1 MB、2 MB，超限取消读取。
- 改用 Electron 异步系统加密，保持磁盘格式；桌面冒烟验证旧同步密文解密及异步加解密往返。
- 语言包为限制大小、校验键和占位符的 JSON，不执行脚本、不定义 HTML、不修改权限或网络目标，React 按文本转义显示。
- 验证码清理仅在剪贴板仍属于本次复制时执行；诊断坚持白名单；可选清理仅针对程序更新下载和旧升级配置副本，带确认及链接拒绝。
- 回归保留路径穿越、压缩包、可信来源、哈希、取消、回滚、依赖和回收站防护；渲染器继续沙箱隔离、禁用 Node 集成、限制导航并验证 IPC 来源。

锁定依赖的公告扫描在检查时未报告已知漏洞。结果依赖公告数据库，不证明依赖没有缺陷；CI 与源码扫描补充而不替代人工检查。

## 边界

Minecraft、第三方加载器及模组以用户权限运行。原始日志、命令行参数和用户内容可能在受控导出之外暴露信息。脱敏是尽力而为，不能替代分享前检查。Windows 用户加密不抵御同用户恶意软件。移除活动账号不自动撤销服务端授权或清除历史备份。安装器未签名。因微软 API 未获批，真实账号验收继续延期。

参考：[Electron 安全清单](https://www.electronjs.org/docs/latest/tutorial/security/)与 [safeStorage API](https://www.electronjs.org/docs/latest/api/safe-storage)。按实际 Electron 版本应用并复测兼容性。
