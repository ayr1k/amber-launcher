# 制作语言包

[English](../LANGUAGE-PACKS.md)

1. 打开设置 → 语言与隐私 → 导出语言包模板。
2. 将 `locale` 设为 `x-fr-fr` 等自定义标识，`name` 填写本语言的显示名称。
3. 翻译 `messages` 的值，保留稳定键及 `{0}` 等数字占位符，不翻译键。未翻译条目可以删除，显示时回退英文。
4. 保存为 UTF-8 JSON，导入并核对确认框后，在语言菜单中选用。当前只有一个自定义语言包位置，导入会替换旧包，应先保留原始文件。

```json
{"format":"amber-language","schema":1,"locale":"x-fr-fr","name":"Français","messages":{"m311bb313fdec":"Comptes"}}
```

文件须为不超过 2 MB 的普通 JSON 文件。标识符合 `x-[a-z0-9-]{2,32}`；名称为 1–60 字符，单条文案最多 8000 字符。未知键、占位符不匹配、受限控制字符和双向覆盖控制字符会被拒绝。导入不执行代码、不修改 URL、路径、权限或下载来源；HTML 只按文本显示。内置中英文不会被替换。语言包保存在 AMBER 用户数据目录，与游戏数据分开。

仅导入可信语言包：即使不执行代码，文案仍可能误导。当前界面为从左向右布局。操作系统原生 UI 和 NSIS 安装器的语言独立；自定义包覆盖 AMBER 界面及应用弹窗文案。升级时保留原包，导出新模板并合并变化条目；未变化文案的键保持稳定。

源码目录为 `prototype/desktop/locales/catalog.json`，每条含中英文。稳定键由源文案生成。新增文案应加入目录并保持占位符一致，自动测试检查整个目录。用户指南同步更新两种语言。

可选的 `formatLocale` 指定日期和数字格式，例如 `fr-FR`。默认使用 `en-US`，须填写有效的 BCP 47 区域标识。
