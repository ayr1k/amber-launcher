# 主题与外观

[English](../THEMES.md)

AMBER 与 AmberE 1.2.1 共用本地 `.ambtheme` 格式，继续读取 1.1.0–1.2.0 主题。设置 → 外观与主题默认展示基础设置；按需开启更多设置和高级编辑。收起选项不会删除其配置。

进入主题库，直接点击“应用”。首次应用一个主题及影响可用性的重大改动需要在 30 秒内确认显示正常，否则自动恢复；相同外观已确认后，切换无需重复确认。“预览与编辑”仅载入草稿，“应用更改”才影响真实界面。可以放弃草稿、恢复上个外观或恢复经典。

导入后可立即应用或仅加入主题库；按范围导入、导出信息放在折叠菜单。Ctrl+Shift+F12 可独立恢复经典外观，不影响账号与实例。窗口圆角下次启动生效；整个窗口透明度也会淡化文字。

首页“编辑首页”提供模块显示、顺序和预设，精细分栏仍在高级编辑中。新增 `calendar`、`news`、`storage`、`tools` 模块；升级不会自动替换当前首页。日历记录、新闻刷新和工具收藏属于本机偏好，不随主题导出。

## 制作主题

最简单的方式是在软件中编辑并导出。也可将 ZIP 改为 `.ambtheme`，根目录直接放置 `theme.json`，图片放在 `assets/<SHA-256>.png`；不要再套一层文件夹。允许可选的 `preview.png` 与 `LICENSE.txt`，当前主题库自行生成控件预览。禁止脚本、CSS、HTML、SVG、字体、远程资源和可执行文件。作者来源和许可仅作展示，不会自动打开。导入不需要官方账号、审核或商城；格式检查不代表可信认证。

参见 [JSON Schema](../theme.schema.json)、[示例](../theme-example.json) 与[完整字段说明](../THEMES.md)。运行时 `prototype/desktop/theme-schema.mjs` 还会检查布局深度、模块重复、图片等约束。

主要字段包括：六类 HEX 颜色、浅深色/系统/自定义模式、圆角与边框、控件和行高、实例图标大小、本机字体与缩放、三种菜单及列表样式、导航文字、三类图片、填充位置/遮罩/模糊、面板及整个窗口的透明度、动画和首页布局。除强调色外的自选颜色在“完全自定义”模式生效。字体缺失或缺字会回退，主题不分发字体文件。

首页用模块、分栏、标签页组成。模块可选启动与账号、快捷操作、任务、实例信息、实例列表、收藏、最近启动、配图；同一模块最多出现一次，必须保留启动模块。模块可拖动交换或通过按钮移动，分栏可拖动或使用方向键调整。最多 32 个节点、5 层、每容器 8 个子项；横向双栏须恰有两个子项，比例为 25–75%，窄窗口自动纵排。

`layout` 提供导航方位、侧栏宽度、内容宽度、实例列表/网格和经典首页顺序。`chrome` 提供窗口边框、标题栏配色、预设/纯色启动背景。导出时，原本的本地启动图会转成主题内嵌图片。

## 安全、兼容与开放边界

主题包最多 32 MiB，64 个文件，解压后合计 64 MiB，单项最多 20 MiB；说明 JSON 最多 128,000 字节。引用的 PNG 必须与文件名的 SHA-256 一致，尺寸非零且不超过 1600 万像素。本地选图会规范化为 PNG。分享前请检查图片许可与个人信息。

格式版本为 1，支持 appearance-v1/layout-v1/composition-v1/home-modules-v1/section-panels-v1。未知必需能力或格式版本会被拒绝；未知可选外观字段会警告后忽略。作者未声明适配当前软件版本时仍允许预览。重名主题各自保存，移出主题库不会删除其他主题可能引用的图片。导出仅包括外观和配图，不包括账号、令牌、实例和本机游戏路径。

本版开放声明式外观，不执行主题作者的代码，也不更改认证、下载等操作含义。未来若增加插件能力，需独立设计权限和版本机制，不把执行代码混入主题包。完整默认体验、渐进编辑、本地自由导入和可恢复性是本版贴近 POP 理念的主要做法。

布局统一在“外观与主题 → 布局”中编辑，经典首页的排序与隐藏仍保留。隐藏导航文字后可将侧栏缩至 72px；恢复文字时自动使用至少 220px，避免文字被挤压。窄侧栏保留名称提示和无障碍标签。

## 1.1.1 精细布局

在“外观与主题 → 布局”中调整纵向启动区、标题和控件尺寸、标题栏与导航尺寸，以及分区留白、间距、背景和分隔线。展开启动选项时，按视口绘制的背景保持尺寸；窄窗口自动纵排。隐藏侧栏附加入口后，仍可从全局搜索打开关于。

1.1.0 主题无需转换。使用新编排或分区样式的主题必须声明 `composition-v1`，旧客户端会拒绝不支持的能力，避免错误显示。基础示例保留对 1.1.0 的兼容。

[下载 AMBER Alloy](../AMBER-Alloy-1.2.1.ambtheme)，适用于两款产品的 1.2.1 及以上版本。选择完整主题导入、应用并在首次确认时检查显示。实例和最近启动均使用真实记录，空库不会产生示例实例。主题独立下载，不自动安装。

## 字体纵向偏移（1.1.2）

在“外观与主题 → 控件与文字”中调整字体纵向偏移：范围 −3 至 +3 px，每次 0.5 px；负值向上，正值向下，默认 0。它微调按钮、菜单和单行输入框的文字，不移动图标、边框或点击区域，也不改变正文段落的布局。可实时预览、归零、撤销/重做，并通过“应用更改”保存。偏移随主题导出；旧主题未声明此项时使用 0。

Alloy 1.2.1 使用向下 1.5 px 的补偿，保留原有图片。现有 Alloy 用户也可手动设置 1.5 px 后应用更改。切换字体后可根据实际显示重新微调。


新版 Alloy 首页采用固定左右分区：左侧启动与底部工具标签，右侧日历与新闻。长内容在所属分区内滚动。“编辑首页”位于标题栏，日历图例与统计口径默认折叠。较窄窗口自动使用整页滚动。


## 官方主题与新版编辑器（1.2.1）

在[官方主题商城](https://ayr1k.github.io/#/themes)预览并下载 Alloy 或 Nocturne。两款主题通用于 AMBER 与 AmberE 1.2.1，独立提供，不预置。Alloy 保留三角纹理背景与窄侧栏；Nocturne 使用夜色湖畔背景、顶部导航与独立新闻/日历面板。

日历统一只显示月份和日期网格。点击日期查看记录，右上角更多按钮打开筛选、总计、记录开关、导出与清除。说明不再常驻首页，记录的统计口径没有改变。

编辑器的导出信息采用独立字段布局，名称必填。保存到主题库不会应用或覆盖同名主题。未应用的外观草稿可以恢复，修改摘要可查看变化，分类恢复默认值仅影响该组。高级布局可设置面板圆角、边框和阴影；旧主题省略新字段时保留原样。

新版主题需 1.2.1；旧 .ambtheme 无需转换。制作与安全限制参见[格式规范](AMBTHEME-FORMAT.md)。
