# 主题与外观

[English](../THEMES.md)

AMBER 与 AmberE 1.1.0 共用本地 `.ambtheme` 格式。入口：设置 → 外观与主题。升级保留当前外观；配色、控件、背景和布局修改先保存在编辑草稿中，可撤销、重做、对比。离开编辑页前，可导出草稿保留个人副本。

在主题库导入文件，查看作者信息，选择完整主题或仅配色、背景、布局，再载入预览。点击试用后有 30 秒确认；未保留便恢复原样，中断重启也会恢复。可恢复上个外观，或按 Ctrl+Shift+F12 独立恢复经典，不影响账号与实例。窗口边框下次启动生效；整个窗口透明度会让文字一起变透明。系统圆角依赖 Windows 11，其他系统可能使用直角。

## 制作主题

最简单的方式是在软件中编辑并导出。也可将 ZIP 改为 `.ambtheme`，根目录直接放置 `theme.json`，图片放在 `assets/<SHA-256>.png`；不要再套一层文件夹。允许可选的 `preview.png` 与 `LICENSE.txt`，当前主题库自行生成控件预览。禁止脚本、CSS、HTML、SVG、字体、远程资源和可执行文件。作者来源和许可仅作展示，不会自动打开。导入不需要官方账号、审核或商城；格式检查不代表可信认证。

参见 [JSON Schema](../theme.schema.json)、[示例](../theme-example.json) 与[完整字段说明](../THEMES.md)。运行时 `prototype/desktop/theme-schema.mjs` 还会检查布局深度、模块重复、图片等约束。

主要字段包括：六类 HEX 颜色、浅深色/系统/自定义模式、圆角与边框、控件和行高、实例图标大小、本机字体与缩放、三种菜单及列表样式、导航文字、三类图片、填充位置/遮罩/模糊、面板及整个窗口的透明度、动画和首页布局。除强调色外的自选颜色在“完全自定义”模式生效。字体缺失或缺字会回退，主题不分发字体文件。

首页用模块、分栏、标签页组成。模块可选启动与账号、快捷操作、任务、实例信息、实例列表、收藏、最近启动、配图；同一模块最多出现一次，必须保留启动模块。模块可拖动交换或通过按钮移动，分栏可拖动或使用方向键调整。最多 32 个节点、5 层、每容器 8 个子项；横向双栏须恰有两个子项，比例为 25–75%，窄窗口自动纵排。

`layout` 提供导航方位、侧栏宽度、内容宽度、实例列表/网格和经典首页顺序。`chrome` 提供窗口边框、标题栏配色、预设/纯色启动背景。导出时，原本的本地启动图会转成主题内嵌图片。

## 安全、兼容与开放边界

主题包最多 32 MiB，64 个文件，解压后合计 64 MiB，单项最多 20 MiB；说明 JSON 最多 128,000 字节。引用的 PNG 必须与文件名的 SHA-256 一致，尺寸非零且不超过 1600 万像素。本地选图会规范化为 PNG。分享前请检查图片许可与个人信息。

格式版本为 1，支持 appearance-v1/layout-v1。未知必需能力或格式版本会被拒绝；未知可选外观字段会警告后忽略。作者未声明适配当前软件版本时仍允许预览。重名主题各自保存，移出主题库不会删除其他主题可能引用的图片。导出仅包括外观和配图，不包括账号、令牌、实例和本机游戏路径。

本版开放声明式外观，不执行主题作者的代码，也不更改认证、下载等操作含义。未来若增加插件能力，需独立设计权限和版本机制，不把执行代码混入主题包。完整默认体验、渐进编辑、本地自由导入和可恢复性是本版贴近 POP 理念的主要做法。

布局统一在“外观与主题 → 布局”中编辑，经典首页的排序与隐藏仍保留。隐藏导航文字后可将侧栏缩至 72px；恢复文字时自动使用至少 220px，避免文字被挤压。窄侧栏保留名称提示和无障碍标签。
