# 安全政策

[English](../../SECURITY.md) · [隐私](PRIVACY.md) · [检查范围](SECURITY-REVIEW.md)

## 报告漏洞

优先使用仓库的 [私密漏洞报告入口](https://github.com/ayr1k/amber-launcher/security/advisories/new)。如果 GitHub 未提供该入口，只在公开 Issue 中询问私密联系方式，不披露利用细节和个人信息。当前不承诺响应时限。

提供版本、平台、影响、使用合成数据的复现步骤，以及可选修复建议。不要公开密码、访问或刷新令牌、账号库、私人日志和真实用户文件。未经授权不测试他人账号或生产服务。

## 支持范围

目前维护目标是 Beta 1.5 Windows x64 预发布版，旧版建议升级。这不是安全认证，也不保证不存在漏洞。

渲染器启用沙箱和上下文隔离、禁用 Node 集成，使用限制性 CSP 和来源校验的 IPC。下载使用可信 HTTPS 来源和完整性校验。语言包仅为受校验的 JSON 文本，不执行脚本。凭据采用 Windows 用户加密，微软 Client ID 为有意公开的信息。游戏和模组以用户权限运行，不处于启动器的安全沙箱中，只安装可信内容。

微软白名单拒绝属于访问审核结果，不能据此认定 AMBER 存在某个具体漏洞。获批前真实微软登录仍未验收。
