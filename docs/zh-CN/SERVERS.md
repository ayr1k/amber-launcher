# 服务端与联机（1.4.3）

1.3.2 反馈修订：统一两种模式的导航图标、软件设置/关于/工具、过渡动画与减少动画规则。首个服务端创建后，创建入口移至实例页；服务器设置、已安装内容归入实例详情。商城共用本地筛选、项目图标和兼容版本选择组件，自动处理必需依赖。联机工具读取服务端日志与配置，截图仍共用本地游戏截图。修正 EULA 对齐。

标题栏的“本地／联机”只切换工作区。客户端实例与服务端实例分别管理，切换不会停止服务器或组网连接。联机一侧的重点色边框提示后台活动，异常状态也有文字提示。服务端运行与远端连通是不同状态。

## 创建与启动

1. 切换至联机，创建服务端实例，选择 Minecraft 版本、核心和未被占用的端口。
2. 原版、Paper、Quilt 和 Fabric 从官方来源准备核心和 Java。Paper 只选稳定构建。Fabric 首次启动会自行准备官方依赖，进度显示在控制台中。
3. Spigot 或 CraftBukkit 创建后需导入自行通过官方 [BuildTools](https://www.spigotmc.org/wiki/buildtools/) 构建的 JAR，再选择合适的 Java。Bukkit 是插件接口；Paper、Spigot、CraftBukkit 提供相应实现。不会提供非官方核心镜像。
4. 阅读 Minecraft EULA，在界面勾选同意后启动。首次启动会生成更多配置项，之后在设置页“重新读取”。
5. 在控制台输入 `list`、`whitelist add 玩家名` 等指令，每次一行。选择“保存并停止”会发送 `stop`，等待进程结束；只有卡住时才使用强制结束。

每个实例在游戏数据目录的 `servers/<实例 ID>/` 中独立保存核心、世界、配置、内容和日志。运行时不能覆盖核心、切换 Java 或更改模组／插件。多个实例可同时运行，启动前检查游戏端口占用；内存由各实例独立指定，请按机器容量分配。

CPU 为服务端进程使用量，100% 代表一个逻辑核心；工作集内存不是 Java 堆大小。没有测量到时显示“—”。不以 CPU 推算 TPS/MSPT，请使用核心支持的性能指令。控制台显示最近约 48 KB，本次控制台日志最多保存约 8 MB；核心自己的 logs 仍由核心管理。

## 设置、内容与恢复

可视化设置仅显示实际文件中存在的已识别选项，按基本信息、世界、访问与身份、网络、性能和高级分类。每项附用途、影响与原值；未知键保持保留，可通过原文编辑处理。取值和可用选项由实际核心版本决定，不给所有版本强行补齐同一套默认值。

保存前展示修改摘要，自动备份旧文件；外部文件已修改时拒绝覆盖。运行期间保存会提示等待重启。重新读取或恢复备份前先处理未保存编辑。切换模式、服务端和设置分类保留当前会话内的编辑；完全退出程序前仍需保存。

Modrinth 搜索按实例的游戏版本和加载器筛选。安装预览列出必需依赖，并检查已知客户端专属内容；元数据不能证明运行兼容性。安装文件先下载校验，再写入实例。同项目其他版本已存在时需先处理旧版，避免同时加载两份。可停用、启用、移除和从恢复记录还原文件；已识别的必需依赖受保护。手动导入 JAR 的依赖需要自行检查。配置文件不会随 JAR 移除。

“复制实例／在副本中升级”在停止后复制世界、配置和内容，源实例保留。不同版本的副本需重新安装目标核心、核对模组和插件；不要直接把世界降级。复制不是自动的异地备份，重要存档请另外复制到其他磁盘。

## 局域网与 EasyTier 房间

同一网络的朋友可直接使用实例概览中的局域网地址。防火墙需允许服务端连接；不自动修改系统防火墙规则。

异地联机页面可下载官方 EasyTier 2.6.4 Windows x64 组件（约 33 MB）。安装包不内嵌组件，首次使用需联网。ZIP 与运行文件均核对固定 SHA-256。组件使用 Apache-2.0 许可证，项目与源码见 [EasyTier](https://github.com/EasyTier/EasyTier/tree/v2.6.4)。

双方安装组件。主持者先启动服务端，填写公共或自建 EasyTier 节点，创建房间并把完整邀请码发给朋友。访客粘贴邀请后，在 Minecraft 中连接界面给出的 `127.0.0.1:端口`。本版本采用 no-TUN 模式，允许房间的游戏 TCP 端口，不创建虚拟网卡或修改 DNS。默认不关闭正版验证。

邀请码包含房间密钥，仅发给可信的人；有效期为创建后 24 小时。离开并重新创建房间会生成新的密钥。仅支持当前启动器维护一个房间连接；服务器本身可有多个实例运行。不同程序接入需使用兼容的 EasyTier 配置。

公共节点用于发现或中继，第三方节点可以获知连接地址和流量信息；其可用性、速度和 NAT 穿透成功率不作保证。“组件运行”只表示进程存在，不等于朋友已连通。若失败，请查看连接日志、节点地址、服务端启动状态和双方网络。更换节点需要离开后重新创建房间。

退出整个启动器时，活动服务端／连接会提示最小化继续运行或停止后退出；正常切换模式不触发这一提示。启动器意外崩溃后，如果服务端进程仍在运行，会阻止该实例被修改，请先结束原进程再恢复管理。

## 验收边界

已在独立测试目录验证官方核心／Java 下载、模拟服务端进程的指令和保存停止、配置冲突／恢复、模式保留以及 EasyTier 多进程经本机中继的 TCP 转发。模拟进程不代表真实 Minecraft 世界、插件兼容性或实际玩家联机已经验收。异地直连／中继、网络切换和重连仍需两台电脑测试。正式版提供该功能，跨电脑联机仍属于测试范围。

## Quilt 与 Sakura Frp（1.4.2）

Quilt 服务端从官方获取加载器与库，使用独立实例目录。Quilt 内容下载接受 Fabric 回退，优先原生 Quilt 版本并保留精确依赖要求。“联机连接”内切换 EasyTier / Sakura Frp；Sakura 需预先创建指向当前服务端回环端口的 TCP 隧道并保存访问密钥。先启动服务端，再启动隧道，等待“已连接”后分享公网地址。“检查连接”检查公开 API、组件和配置。配置经过 HTTPS 证书校验获取，通过子进程内存交给 frpc，不保存明文配置。停止并退出启动器会停止连接。

已通过真实 Sakura 公网隧道读取 Paper 26.3 的 Minecraft 状态并正常停止测试组件；不代表全部网络线路、模组/插件或非 Windows 运行环境均已验收。

## 1.4.3：下载并发与联机实例回收站

在设置中选择同时下载文件数，最高 128，默认仍为 8，已有设置保留。任务共用额度并公平获得空闲通道；网络失败或限流后降低并发，连续成功后逐步恢复。这不是单文件多段下载，较高值不一定更快；连接或来源变慢时可以调低。服务端内容与依赖并行下载后继续校验并安全提交。

在“联机 → 实例”点击删除，会先移入应用回收站；需要先停止服务端及其隧道，并完成或取消关联任务。进入回收站可以恢复；端口被占用或分配给其他实例时，可以改用其他端口，恢复不会自动开服。彻底删除需输入完整实例名称，会删除该实例的世界、配置与内容；独立备份以及共享 Java、下载缓存保留。

## 1.4.4：服务端更新、性能和下载控制

在“联机 → 实例 → 内容 → 检查更新”（也可从“内容下载 → 已安装内容”进入）检查兼容的 Modrinth／CurseForge 更新，锁定版本并预览所选更新与依赖。安装、恢复前需停止服务端，并遵循已设置的自动备份策略；校验后的恢复副本保留旧文件。直接恢复要求更新后的文件没有再变化，不恢复配置和世界。没有来源记录的手动文件需手动管理。

联机启动页展示最近十分钟 CPU、工作集内存及受支持的 TPS／MSPT。停止服务端后安装或更新性能与玩家增强组件，再开服。Paper 提供真实 tick 指标，不支持的核心显示不可用。可主动采集 30 秒本地报告并导出 JSON；报告仅含有界数值样本和事件类别，不自动上传，也不能据此确定某个插件就是卡顿原因。

设置／任务中心支持全局下载限速，单位 KiB/s，0 表示不限速；显示实际传输数和排队数。优先任务取得下一批空闲通道，不中断已有传输。限速针对文件下载正文，不是整个软件所有网络流量。
