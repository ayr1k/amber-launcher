# 1.7.5 更新源

GitHub 全球源保留为旧用户默认，一般适合海外，国内连接可能受限。官方镜像位于中国香港，为大陆及周边提供另一线路；速度取决于网络，可能同步延迟。不会按 IP 分流、承诺速度或静默换源。

## 协议及信任边界

继续使用 `app-updates.mjs` 自研更新器，不是 electron-updater。协议 1 使用 GitHub 作为版本及摘要权威、镜像仅传输字节。软件不读取公开下载 `/mirror/v1/index.json`；无需官网配套部署。

从对应产品 GitHub Releases API 获取有大小上限、20 秒请求超时、禁重定向且 no-store 的元数据；稳定通道另读 latest。只选最高符合通道版本，不降级，也不在最新版本缺安装包或摘要时回退旧版本。严格核对产品、平台、架构、文件名、大小、uploaded 状态、GitHub SHA-256 及精确下载 URL。

软件内支持 Windows x64、macOS x64/arm64、Linux x64；其他平台/架构明确报不支持。香港镜像仅 stable，按固定路径 `/mirror/v1/{amber|ambere}/{version}/{filename}` 派生 URL，HEAD 禁重定向并与 GitHub 大小比较。未同步及失败均提示重试或手动换源，不称最新。镜像摘要不是独立签名，也不作为权威。

每次下载（含重试）和安装前重新读取权威、核对候选身份；替换/撤回要求重新检查。下载维持大小限制、按摘要隔离片段、SHA-256、取消和安装前文件复验；镜像不能重定向。候选超过 15 分钟或时钟倒退要求重新检查下载。用户确认与配置备份后再复验。

信任模型仍包含仓库发布权限、GitHub API 及 TLS；未引入独立签名密钥。GitHub 不可达时，即使镜像文件可达，也不能检查、刷新或安装。no-store 及复验不能证明全球最新状态，也无法防止权威本身返回过期数据。preview 保留最近 30 个 Release 的现有限制。

## 配置与竞态

`update-channel.json` schema 2 独立保存 source/channel；旧 schema 1 保留通道并默认 GitHub。损坏配置提示错误但不阻止启动。镜像+preview 明确失败，不替用户换通道。切源清空候选；配置写入、检查、下载及安装校验相互排斥。取消安全结束后才能切源；缓存必须重新取元数据并校验字节才能复用。

## 验证限制

`update-sources175.test.mjs` 使用 mock 元数据与合成安装包字节，覆盖产品/平台、旧配置、失败、过期、替换、篡改、取消和切换。真实端点探测另记，只证明连通性/元数据，不代表安装升级成功。原生界面、两款 Windows 安装包验收、真实 1.7.4→1.7.5 升级及回退仍作为单独验收限制；本次正式发布已获授权。保留有意义的 GitHub 仓库、Release、反馈链接。
