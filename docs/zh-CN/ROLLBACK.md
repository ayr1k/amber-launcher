# 从 1.2.2 回退

先关闭游戏和下载任务，备份重要实例与设置，再安装对应产品的 [1.2.1](https://github.com/ayr1k/amber-launcher/releases/tag/v1.2.1)。保留游戏库，现有主题无需转换。旧版不会恢复本版新增的单独下载记录或文件片段续传，请先完成或取消下载。回退程序不会撤销存档或模组变化。

# 从 1.2.1 回退

先导出当前外观并备份实例、存档与设置。切换到经典外观或 1.2.0 主题，关闭游戏和启动器，再安装同一产品的 [1.2.0](https://github.com/ayr1k/amber-launcher/releases/tag/v1.2.0)。不要向旧客户端导入声明 `section-panels-v1` 的 Nocturne 等新主题。程序回退不撤销存档或模组变化，不要删除游戏库。两款产品使用独立数据目录。

# 从 1.2.0 回退

先导出当前主题并备份重要实例、存档和配置。恢复经典外观或 1.1.2 Alloy，关闭游戏和启动器，再安装同一产品的 [1.1.2 安装包](https://github.com/ayr1k/amber-launcher/releases/tag/v1.1.2)。不要向旧版导入使用新首页模块的 Alloy 1.2.0。两款产品的数据目录不能混用。

程序回退不回退存档或模组修改；必要时把实例备份恢复到独立实例。游玩记录、新闻缓存和存储摘要独立保存在本地，旧版不使用这些功能；不要为回退而删除整个游戏库。

# 从 1.1.1 回退

回到 1.1.0 前先导出主题并恢复经典。单独保存导出文件：1.1.0 不理解 composition-v1 和分区样式，重新升级后再导入。游戏数据回退仍需要独立备份。

# 从 1.1.0 回退

更换版本前，在设置 → 外观与主题中导出当前外观，单独保存 `.ambtheme` 文件，再按 Ctrl+Shift+F12 恢复经典。1.0.0 不支持 1.1.0 的主题系统。

备份重要实例与存档，关闭启动器和 Minecraft。下载对应产品的 [1.0.0 安装包和校验文件](https://github.com/ayr1k/amber-launcher/releases/tag/v1.0.0)，核对 SHA-256 后安装到原程序目录，保留用户数据。不要混用 AMBER 和 AmberE 的安装或数据目录。主题包可以跨这两款产品使用，账号库和游戏数据目录不能直接混用。

回退程序不会撤销模组、配置或存档变化；需要时将实例备份恢复到独立实例。主题文件仍保存在本地，但旧版可能规范化其不认识的设置，因此重新升级前请保留导出的主题，不要依赖旧版继续保存主题偏好。

安装前检查会在适用时保留旧程序，位置记录在 `%LOCALAPPDATA%/AMBER/previous-program.txt`；这不是存档备份。账号加密需要原 Windows 用户。

如需从 1.0.0 继续回退，[Beta 1.14](https://github.com/ayr1k/amber-launcher/releases/tag/v1.0.0-beta.15) 仍可下载，同样需要备份并区分产品。
