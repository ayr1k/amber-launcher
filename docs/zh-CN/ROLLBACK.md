## 1.4.0 → 1.3.6

停止游戏与服务端并退出启动器，备份完整游戏库和设置后安装同产品 1.3.6。保留 1.4.0 快照和待完成升级记录；旧版本不支持这些新增流程。备份或升级进行时不要降级。

## 1.3.6 → 1.3.5

Windows 用户先停止游戏与服务端、退出启动器，并备份账号配置和游戏库，再从对应产品 Release 安装同产品 1.3.5。本次未主动迁移账号或存档格式，保留现有数据即可；1.3.5 不包含新增崩溃分析及本次布局、分页修复。其他平台下载仍为 1.3.5。

## 1.3.5 → 1.3.4

回退包仅有 Windows 版本；macOS/Linux/FreeBSD 无对应旧版官方包。退出游戏和服务端并备份完整账号配置与游戏库后，安装同产品 1.3.4。旧版不支持自定义离线皮肤；AMBER 旧版会检查离线名称与官方名称一致，必要时先在 1.3.5 中恢复名称。不要覆盖账号库或删除存档来解决登录失败。跨系统迁移时重新登录，勿复制加密凭据。

## 1.3.4 → 1.3.3

保存并停止服务端，关闭游戏与启动器，备份完整游戏库和应用数据后，可安装同一产品的 [1.3.3](https://github.com/ayr1k/amber-launcher/releases/tag/v1.3.3)。旧版不含种子地图及新增配色格式；请保留导出的标记与渐变作品，旧版可能不识别新选项。导入的实例是独立副本，回退不会删除它们，也不会撤销世界内容变更；导入没有修改原 .minecraft 目录。

## 1.3.3 → 1.3.2

保存并停止服务端、关闭游戏和启动器，备份重要存档后安装同一产品的 [1.3.2](https://github.com/ayr1k/amber-launcher/releases/tag/v1.3.2)。保留完整游戏库和应用数据；本维护版本不改变实例或主题格式。回退启动器不会撤销游戏、模组或世界的变更。

## 1.3.2 回退至 1.3.1

先保存并停止所有服务端、断开房间、退出启动器，再安装保留的 1.3.1 安装包。保留整个游戏数据目录，尤其是 `servers/`、存档和配置备份。1.3.1 不管理新增的服务端目录，不要删除它。Minecraft 服务端版本降级需恢复升级前的存档副本；回退启动器不会降级存档。

# 从 1.2.3 回退

# 从 1.2.2 回退

# 从 1.2.0 回退

程序回退不回退存档或模组修改；必要时把实例备份恢复到独立实例。游玩记录、新闻缓存和存储摘要独立保存在本地，旧版不使用这些功能；不要为回退而删除整个游戏库。

# 从 1.1.1 回退

# 从 1.1.0 回退

更换版本前，在设置 → 外观与主题中导出当前外观，单独保存 `.ambtheme` 文件，再按 Ctrl+Shift+F12 恢复经典。1.0.0 不支持 1.1.0 的主题系统。

备份重要实例与存档，关闭启动器和 Minecraft。下载对应产品的 [1.0.0 安装包和校验文件](https://github.com/ayr1k/amber-launcher/releases/tag/v1.0.0)，核对 SHA-256 后安装到原程序目录，保留用户数据。不要混用 AMBER 和 AmberE 的安装或数据目录。主题包可以跨这两款产品使用，账号库和游戏数据目录不能直接混用。

回退程序不会撤销模组、配置或存档变化；需要时将实例备份恢复到独立实例。主题文件仍保存在本地，但旧版可能规范化其不认识的设置，因此重新升级前请保留导出的主题，不要依赖旧版继续保存主题偏好。

安装前检查会在适用时保留旧程序，位置记录在 `%LOCALAPPDATA%/AMBER/previous-program.txt`；这不是存档备份。账号加密需要原 Windows 用户。

如需从 1.0.0 继续回退，[Beta 1.14](https://github.com/ayr1k/amber-launcher/releases/tag/v1.0.0-beta.15) 仍可下载，同样需要备份并区分产品。
