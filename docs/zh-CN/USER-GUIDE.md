# 使用指南

[English](../USER-GUIDE.md)

**首次使用：** 选择语言和游戏数据位置。AMBER 引导前往账号页验证 Minecraft Java 版正版资格；可跳过以管理实例，但未验证资格不能启动。AmberE 可以直接创建离线身份，也支持第三方账号，不提供微软登录。两个版本使用独立数据目录。

**AMBER 账号资格：** 微软与关联的第三方账号在启动时在线验证官方账号。验证成功后可主动创建沿用官方角色名称和 UUID 的离线身份；加密资格缓存最多七天，离线使用不续期，检测到时钟回退或后续明确的授权/资格拒绝会停止使用，移除关联官方账号也会阻止启动。旧的未验证离线账号仍显示，但不能启动；原实例与存档不改动。这一缓存策略不代表 Mojang 批准，详见[测试与限制](TESTING.md)。

**安装：** 点击创建，选择 Minecraft 版本，再选择兼容组件和名称。禁用项说明不兼容原因。AMBER 准备 Java 并校验下载。失败时前往任务中心重试，复用已校验文件；完整安装计划可跨重启继续。

**下载内容：** 先选择目标实例，Modrinth 搜索、分类和排序保持游戏/加载器兼容条件。必需依赖默认勾选，可在警告下取消；可选依赖默认不勾选。确认变更预览后安装。光影需要对应加载支持，作者元数据不能保证所有运行组合。

**管理：** 筛选、批量启停与移除内容，导入本地 JAR/LiteMod，检查兼容更新并锁定版本。操作记录可恢复适用的内容变更，保护外部修改；旧内容记录不恢复存档与配置；实例工作台另行记录受支持的配置变化。

**保护存档：** 迁移或批量操作前备份，恢复为新实例，另存一份到其他磁盘。实例删除先进入 AMBER 回收站；彻底删除需输入完整名称且不可撤销。

**启动：** 选择账号和内存，实例独立设置优先于全局默认。实例检查核对 Java、文件、已知依赖与账号选择。出错后使用解决入口；分享日志前检查，优先导出设置中的诊断摘要。

**语言与外观：** 设置内即时切换语言、导入语言包、选择主题与圆角、本地背景、透明度、布局和减少动画。用户/项目名称不变，可用本地化关键词查找设置。

先退出游戏与任务，不会在后台自动安装。

## 窗口外观与隐私工具

设置 → 外观与背景 → 窗口，可选择直角／系统圆角边框和标题栏配色。边框下次启动生效，控件圆角独立设置。系统圆角需要 Windows 11，较早 Windows 使用直角。拖动标题栏空白处移动窗口，双击最大化／还原；Win + 方向键用于分屏，自定义最大化按钮不提供原生悬停分屏菜单。窗口记住正常位置、尺寸和最大化状态，显示器断开时恢复到可见区域。Alt 不再唤出应用菜单；保留 Ctrl+A/C/X/V/Z/Y、Ctrl+Shift+Z/V 编辑快捷键。

设置 → 语言与隐私，按数据位置、诊断与分享、清理与维护分区。路径旁的按钮可以复制路径。先预览诊断摘要，再选择导出位置。清理会明确提示受影响的副本，保留活动账号、实例、存档和实例备份；取消时不会显示为清理成功。

## 显卡偏好（Beta 1.7）

设置 → 游戏启动与首页展开的启动选项控制同一项全局显卡偏好。选择高性能或节能后，下次启动会为实际游戏 Java 应用当前 Windows 用户的程序图形偏好，不会修改 AMBER 自己的渲染显卡。共用 Java 的实例也共用系统偏好；更换 Java 后会在后续启动时处理新路径。

切回“跟随系统”会尝试还原 AMBER 修改过的偏好；“恢复 AMBER 修改的显卡偏好”也可清理剩余记录。系统中另作的修改会保留。恢复记录保存在 AMBER 用户数据目录的 `graphics-preferences.json` 中；如需还原原值，请先恢复，再清理记录。卸载保留用户数据。

自动应用使用 Windows 当前用户的程序图形偏好存储，需要 Windows 10 2004 或更新版本，可能受组织策略或未来系统变化影响。无法自动应用时可打开系统图形设置，并复制游戏 Java 路径。实际显卡由 Windows、驱动与硬件决定；渲染设备根据可识别的游戏日志行显示，“未检测到”不等于启动失败或正在使用核显。专用测试记录的写入与恢复验证不代表真实游戏已完成双显卡切换验收。

## Beta 1.12 工作台与试用副本

打开实例 → 概览与检查。安装状态、文件/依赖检查与“我已游玩，确认运行正常”各自独立；后者是你的实际确认，不代表启动器自动完成了游戏兼容认证。

选择 **创建试用副本**，也可以从模组更新或补装推荐入口进入。先检查磁盘空间，可选复制存档。副本使用独立文件，不共享可写存档，需要另选账号。请在副本内重新生成推荐或检查更新，再安装内容。

测试后选择 **预览应用回原实例**。配置可以按文件勾选，应用时替换整个文件；内容文件与清单作为一组保持依赖一致性。账号、存档和世界进度不回写。原实例或预览后的文件发生变化时停止操作，不强制覆盖；应用前创建恢复记录。也可以将试用副本保留为普通独立实例。

**变更记录** 包含受支持的内容操作、启动和画面配置修改。外部修改会显示，但没有事前备份时不能自动恢复。只有文件和游戏/加载器仍与记录匹配时才能恢复。中断的应用事务在核对文件后恢复；遇到意外外部修改会停止。操作进行期间不要删除恢复文件。本地异常指引区分日志证据与近期变更，提供线索，不保证判定全部原因。

按 **Ctrl+K** 或点击标题栏搜索图标查找实例和操作；方向键选择、Enter 执行、Escape 关闭。内容页保留筛选条件，并在空间足够时使用列表和详情布局。

在引导创建或补装推荐中展开 **本地推荐模板**，保存、导入或导出偏好 JSON。只交换问卷偏好，不含已安装模组、账号或存档。导入前校验并确认，使用模板后仍需重新生成兼容方案；无效、过大或重名模板会被拒绝。


## 更新与维护（Beta 1.14）
在“设置 → 下载”选择稳定版或测试版通道。未主动保存过通道时，Beta 默认接收测试版，新安装的正式版默认只接收稳定版。切换通道不会自动降级或安装。下载、校验和确认安装分开进行；升级前结束游戏和活动任务。

“设置 → 数据与引导 → 存储与维护”仅在主动扫描时统计主要目录。统计值不等于实际可释放空间；清理只针对程序更新下载或升级前配置备份，需要再次确认，不清理共享游戏依赖或活动实例。

实例“备份”中的“校验备份”检查文件哈希，不创建实例；恢复创建独立实例，不覆盖原存档。重要备份仍建议另存到其他磁盘。

数据磁盘断开时，启动恢复提示可重试、定位原库或退出。重新连接磁盘，或选择含 instances 的原目录；不会静默创建替代空库。迁移中断时可重新连接原目录，复制校验成功前不会切换配置位置。

诊断导出保存上次预览的同一份摘要，不自动附带原始日志或账号数据。第三方日志分享前仍需自行检查。

## 外观与主题

在设置 → 外观与主题调整配色、菜单、列表、背景与首页布局。主题库可导入兼容 AMBER / AmberE 的 `.ambtheme` 包；主题库可直接应用。首次应用及较大改动需在 30 秒内确认，否则自动恢复；已确认且未改变的主题可一步切换。Ctrl+Shift+F12 恢复经典外观。详见[主题帮助](THEMES.md)及[主题格式](AMBTHEME-FORMAT.md)。

## 个性化首页与实用工具（1.2.0）

标题栏“编辑首页”可调整模块、选择简洁/日常/信息预设。正常窗口优先单页浏览，启动、日历和新闻等分区可独立滚动；较小窗口或放大后自动使用整页滚动。更多设置 → 布局可选择浏览方式，高级编辑可组合分栏、标签与整体滚动分区。

游玩日历显示本地可观察的运行时长；可能包含挂机，并非活跃游玩时间。点击日期查看记录，在日历更多菜单中查看统计与记录设置。记录可关闭、导出或清除，不补造旧记录时长。新闻默认手动刷新，可按类别筛选；可选自动刷新、离线缓存和更新说明不会阻塞游戏启动。

实用工具提供 Java 检测、日志入口和本地 PNG 截图浏览。截图可按实例/日期筛选、预览、复制或打开文件夹；不上传图片。存储与维护按需扫描占用，扫描可取消，清理仍需确认并保护活动数据。

外观与主题默认展示基础设置，需要时开启更多设置或高级编辑。主题库可直接应用主题，预览与编辑为可选操作。新版 Alloy 单独下载并导入；详见[主题帮助](THEMES.md)。


## 主题编辑与日历（1.2.1）

官方主题统一从[主题商城](https://ayr1k.github.io/#/themes)下载。导入后可直接应用或先编辑。外观编辑器会保存尚未应用的草稿，恢复草稿后需自行应用；“保存到主题库”保留为独立主题，不立即切换，同名时需更名。导出名称不能为空。

日历默认仅显示月份与日期；点击日期看记录，更多按钮内调整筛选和记录设置。顶部导航有独立的关于入口，不再在各页面底部重复显示。

## 下载连接（1.2.2）

设置 → 下载 → 下载连接提供**自动选择、官方源优先、中国大陆优化**。自动模式比较轻量连接探测结果，并缓存十分钟；不获取用户地区，也不保证加速。官方优先与大陆优化在失败后可回退到另一来源，在“更多下载设置”中可关闭回退。镜像只处理明确支持的 Minecraft 元数据、资源和 Maven 地址；Modrinth、Java 提供方及账号认证继续使用各自来源，内容下载可切换 Modrinth / CurseForge。

任务中心展示来源、下载字节、当前速度和文件详情。暂停针对正在下载的阶段，保留任务占用和文件片段；暂停期间也能取消。准备、解压和安装收尾不能暂停。速度仅代表当前观测，后续阶段解析出新文件时总量可能增加。

下载片段以 `.amber-<hash>.part` 结尾，位于对应下载文件旁。服务器支持合法范围响应时续传，否则重新下载当前文件；完整大小和哈希校验通过后才变成可安装文件。校验失败会丢弃片段，取消不会删除已完成文件。重启后任务不会自行运行，请在任务中心选择继续。完整安装/内容计划及单独游戏、Java 准备任务支持恢复；单次模组更新可能需要回到实例重新检查更新。

“检查下载连接”探测 Minecraft、BMCLAPI、Modrinth 和 Fabric 的公开地址，不发送账号或实例资料，也不代表所有文件可用。复制的摘要仅包含服务名称、状态与耗时；网络提供方仍能看到普通连接信息。适用的游戏/加载器失败任务可以切换来源后继续，其他任务可在任务中心展开下载策略调整。弱网自适应只降低本次后续并发，不修改保存的最大并发数。

镜像服务与地址规则：[BMCLAPI · bangbang93](https://bmclapidoc.bangbang93.com/)。可用性和内容完整度取决于服务提供方。

## 本地整合包、模组清单与备份（1.2.3）

在“内容 → 已安装内容 → 已安装文件”点击“导入整合包”，或从创建实例界面进入。整合包始终创建独立实例，不与当前实例合并。MRPACK 的游戏和加载器按作者清单准备，支持原版、Quilt、Fabric、Forge 和 NeoForge；其他组合会说明不支持。可选客户端文件默认不选择，服务端专用文件不安装。

内容 ZIP 可包含 mods、config、resourcepacks、shaderpacks、saves、defaultconfigs、kubejs、scripts、options*.txt 和 servers.dat，支持单一外层目录／.minecraft 包裹。没有标准版本清单时必须核对作者要求并选择版本；检查可识别的模组加载器、明确游戏版本与重复模组标识，不保证完整依赖或实际游玩兼容。不执行 ZIP 内的启动或安装脚本。包内的模组及游戏脚本会在游戏运行时生效，请使用可信来源。

当前限制为压缩包 300 MB、解压后 600 MB、单文件 256 MB、最多 10000 项，不支持 ZIP64、分卷或加密压缩包。预览中的大小只统计整合包内容。创建前为源包、内容缓存及安装副本检查空间，并额外预留 1 GB；游戏、Java、加载器总大小仍可能超过预留空间。大型整合包可由作者精简附带文件后重新导出。

MRPACK 通常仍需联网下载清单中的文件，只有受信任来源可自动下载，校验通过后才安装。原包保存在新实例的 .amber-setup/local-pack.zip；不要在未完成安装时删除它。关闭后可到任务中心继续，原始下载位置的压缩包移走不影响恢复。失败实例不会冒充可启动状态，可继续、查看文件或从实例列表移入回收站。

实例概览可查看整合包来源、导入时间和跳过项；完整内容记录位于 modpack.json。本地整合包不会自动追踪整包更新，单独升级模组建议先使用试用副本。

模组清单只记录项目身份、版本提示与启用状态，用于重新寻找兼容模组，不含 JAR、配置或存档，不能完整复原整合包。通过“迁移到其他版本”导入或导出清单。实例备份恢复的是备份时选定的数据，使用“备份与恢复”。CurseForge 清单 ZIP 可导入并预览依赖，尊重作者下载限制；其他启动器的完整实例档案暂不支持本入口。

实用工具的 Java 页面可检测环境、复制路径和查看已配置实例引用；引用列表不代表所有实例最终自动选择的 Java。日志页可选择实例，分别进入日志查看或打开日志文件夹。固定到首页只改变快捷入口，不影响工具功能。

## 可视化工具与配置编辑（1.3.0）

账号显示皮肤头部和帽子层，点击头像可刷新；失败时使用匹配缓存或默认头像。第三方纹理仅允许皮肤站自身主机或 Minecraft 纹理主机。

实用工具 → 截图浏览器可浏览全部或指定实例，按文件时间排序、按日期或实例分组。打开缩略图后可缩放、前后切换、复制或定位原文件；分组不会移动文件。

实例内容 → 依赖关系可搜索、缩放、拖动节点，筛选必需／可选／冲突声明并恢复自动排列。箭头从模组指向依赖。显示安装记录及可识别的 Fabric／Quilt 声明；未知或未解析声明不代表无依赖，也不证明运行兼容。拖动不会改变安装内容。

实用工具 → 文件编辑器支持 config/defaultconfigs/kubejs/scripts 及部分根目录文本文件。多标签保留修改，Ctrl+S 保存、Ctrl+F 查找；搜索面板支持替换。提供行号、语法分色、撤销重做；格式化和保存校验仅适用于 JSON。只支持 2 MB 内 UTF-8 文本，不支持 NBT 或执行脚本。保存前关闭游戏；外部修改会阻止覆盖。每次保存生成相邻 .bak 备份，“历史备份”先将旧内容放入编辑区，点击保存才恢复。备份可能包含私人配置，分享前请检查。

渐变文字支持多个色标与位置调整、反转、粗体、本地预设、复制与导出。JSON 是文本组件，MiniMessage 和十六进制色码需要对应插件支持。中文和组合表情按完整字符处理。

已有主题保持导航与贴边位置。大窗口限制侧栏与底部辅助区大小，多余空间用于背景，主题包无需转换。

## 渐变文字选区格式（1.3.1）

在实用工具 → 渐变文字中选中文字，再应用纯色、局部渐变、粗体、斜体、下划线或删除线。点击格式工具后选区保留，混合格式会显示状态。没有选区时格式操作禁用；需要修改整段时明确勾选“应用到全文”。重新选中文字会回到只修改选区。

“清除格式”恢复基础渐变与普通字重。修改基础渐变会保留局部颜色；局部渐变在选区内重新计算起止颜色。文字、样式与配色修改均可撤销重做。粘贴使用纯文本；文本最多 4000 个 UTF-16 单元，组合表情按完整字符设置格式。

在“配色预设与作品”内填写保存名称。“保存配色”兼容旧预设，“保存完整作品”额外包含文字与局部格式，保存在本机。载入作品需确认替换当前内容，且可以撤销。离开工具前请保存需要保留的作品。

JSON 为 Java 文本组件，不包含命令；MiniMessage 与十六进制色码需要对应插件支持。文字含有可能被插件解释为格式的色码时，会阻止十六进制输出；可改用 JSON 或 MiniMessage 保留原文字。预览使用启动器字体，游戏中的字体与渲染可能不同。

## 种子地图、渐变工作区与原版目录导入（1.3.4）

**种子地图：** 两种模式均可从实用工具 → 种子地图进入。输入数字或文字种子，选择匹配的 Java 生成版本与维度，X/Z 用于定位，Y 用于选择生物群系高度切片；点击“查看地图”应用。拖动时实时移动，滚轮或加减按钮缩放，左下显示比例尺，新区域在后台生成。地图上方提供可检索的生物群系选择、结构筛选与标记操作。填写名称，点击“添加标记”后在地图上点选位置；已保存标记可跳转、导出和导入 JSON，最多 500 项。“读取 level.dat”只读取种子和出生点，不修改世界；无法匹配版本时请手动核对。

地图预测受支持的 Java 原版生成，不是已探索区块读取器。支持三维度及 1.7.10 至 26.3 范围内列出的生成版本，不支持基岩版或自定义生成器。阴影是估算高度，并非逐方块地形；结构可能受地形、数据包、模组及跨版本生成影响。查看史莱姆区块或密集结构时请放大。内置 Cubiomes/xpple 引擎可离线运行，种子和标记保存在本地。

**渐变文字：** 左侧编辑文字，右侧调整颜色并查看输出，窄窗口改为上下排列。支持颜色面板、色相条、HEX 编辑、HEX/CSS 配色导入与随机配色，保留选区样式、局部渐变、撤销重做和本地作品。选择七种输出格式之一后复制或导出；插件格式仍需目标插件支持，预览颜色不代表所有游戏版本均可使用。

**导入 .minecraft：** 在本地模式的“实例”页点击“导入 .minecraft”，选择原版启动器目录及可识别的启动配置。核对游戏、加载器、源游戏目录和要复制的内容，命名新实例后点击“复制并安装”。受支持的 Vanilla/Quilt/Fabric/Forge/NeoForge 配置由可信元数据重建，复用已通过哈希校验的本地库和资源，识别自定义 gameDir 与版本继承。复制前请关闭源游戏。不导入账号、凭据和任意启动参数；源目录保持不变，导入结果是独立副本，不直接链接共用游戏目录。不支持的自定义客户端会明确显示。

取消或后续下载失败会保留源文件，也可能留下未完成的新实例。若复制中断，先重新导入到新实例，再处理未完成副本；Java 可通过原有启动流程准备。重要存档仍应单独备份，导入检查不等于所有模组与游戏组合的兼容性验收。

## 1.3.5：离线用户名、皮肤与平台

在“账号”中展开离线身份的“编辑用户名与皮肤”。名称为 3–16 个英文字母、数字或下划线，保存后 UUID 不变。支持 64×64 / 64×32 PNG；窄手臂需要 64×64。可切换模型或恢复默认皮肤。名称型服务器可能把改名后的角色视作新玩家；修改前确认规则。

AMBER 仍要求关联的正版资格及有效离线缓存；AmberE 不提供微软登录。皮肤保存在加密账号记录中，仅由本机为游戏提供；首次使用下载兼容组件，此后复用缓存。使用皮肤时保持启动器运行，其他玩家不一定可见。

Windows 使用 EXE；macOS 按芯片选择 ZIP；Linux 使用软件包管理器安装 DEB 及依赖，并配置桌面密钥库；FreeBSD 实验包只支持服务端/工具，不能作为完整客户端使用。[平台安装与验证范围](../../prototype/PLATFORMS-1.3.5.md)。账号密文不能跨操作系统直接迁移。


## 1.3.6 崩溃原因分析

在“实用工具 → 日志与诊断”选择实例后点击“分析最近一次运行”，或选择不超过 2 MB 的 .log / .txt 文件。异常退出页面也会显示分析。可展开日志依据查看原文；未知错误会明确提示无法确定原因。

识别范围包括 Fabric 缺失/不兼容依赖、必需依赖提示、插件依赖、Java 版本、内存预留/运行时内存、端口绑定、损坏 JAR、图形初始化及声明冲突。Mixin 失败仅标为可能原因。当前启动时间用于排除旧日志；缺少运行记录时可手动导入，不猜测历史原因。不会自动安装、删除模组或修改设置。

## 1.4.0 自动保护与联机管理

本地实例 → 管理 → 备份与恢复：可启用每日首次启动前、正常退出后、模组/加载器更新前备份。联机实例 → 管理 → 备份与客户端：可启用每日首次启动前、正常停止后，以及安装/更新核心、模组或插件前的完整备份。策略按实例保存，默认关闭；服务端运行中不复制世界，强制终止和异常退出不触发停止后备份。

设置自动备份数量和容量，重要记录可固定。手动和固定备份不会自动清理，至少保留最新自动备份。备份失败阻止对应启动/更新；刷新备份记录可查看新增快照。恢复创建独立实例，服务端分配不同端口且新实例自动备份默认关闭。备份在同一磁盘，仍需另存重要世界。

整合包升级支持本地 MRPACK 或已有 Modrinth 来源的新版，预览本地修改/删除冲突后创建新实例，失败可继续准备。服务端玩家操作与常用指令经控制台执行，请核对返回结果。关联客户端可检查可识别的环境差异、预览缺失依赖，并启动加入本机服务端。环境清单只分享版本和模组来源，不含世界、账号、服务器地址或房间密钥；导入创建独立实例。未知来源需手动核对，声明关系不能保证完整兼容性。

崩溃分析中的依赖修复入口打开兼容内容搜索与安装预览，由用户确认安装，不静默修复。

## 1.4.1

内容下载页的平台选择器可切换 Modrinth / CurseForge。按实例版本筛选，安装前检查依赖；不会绕过作者禁止第三方下载的限制。CurseForge manifest ZIP 可导入独立实例。

联机 → 玩家：进入自动刷新，在线时定时更新。名单独立滚动，底部输入名称即可向未入服玩家添加白名单；服务端运行时执行。每行选择操作后点击执行，踢出/封禁/管理员操作需确认，请查看控制台反馈。头像来自已知 UUID 的公开皮肤；无法获取使用占位。Ping 由可选 Paper/Spigot/CraftBukkit 玩家信息插件提供：停止服务端后安装、重启生效。原版/Fabric 或无插件时显示不可用。

## 1.4.2：Quilt 与 Sakura Frp

手动/引导创建、加载器配置、受支持整合包导入及服务端创建均可选择 Quilt。Quilt 模组搜索、版本与依赖解析也接受 Fabric 版本，优先 Quilt 原生版本，保留作者固定的依赖版本；不代表每个 Fabric 模组或组合都保证可运行。

联机 → 联机连接提供 EasyTier / Sakura Frp 二级标签。在 Sakura 官网创建指向 127.0.0.1 和当前服务端端口的 TCP 隧道；下载官方组件，保存访问密钥及当前实例的隧道 ID，启动服务端后启动隧道。密钥在本机加密保存；AMBER 保留 TLS 校验，通过官方 API 获取配置，交给 frpc，不保存明文配置文件。等待显示“已连接”后再分享公网地址。“检查连接”检查 API、组件和已保存配置，连接日志保留技术信息。修改已保存配置前先停止隧道。

## 1.4.3：下载并发与联机实例回收站

在设置中选择同时下载文件数，最高 128，默认仍为 8，已有设置保留。任务共用额度并公平获得空闲通道；网络失败或限流后降低并发，连续成功后逐步恢复。这不是单文件多段下载，较高值不一定更快；连接或来源变慢时可以调低。服务端内容与依赖并行下载后继续校验并安全提交。

在“联机 → 实例”点击删除，会先移入应用回收站；需要先停止服务端及其隧道，并完成或取消关联任务。进入回收站可以恢复；端口被占用或分配给其他实例时，可以改用其他端口，恢复不会自动开服。彻底删除需输入完整实例名称，会删除该实例的世界、配置与内容；独立备份以及共享 Java、下载缓存保留。
