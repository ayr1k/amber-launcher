## Beta 1.8 — 1.0.0-beta.9（预发布）

- AMBER 在实际游戏启动入口统一检查正版资格，拦截匿名及旧的未验证离线启动；微软账号在线检查资格和角色，第三方账号在线检查关联的官方账号资格。认证失败不自动降级为离线模式。

- 本预发布附 Windows 安装包、源码包与 SHA-256 校验文件。微软 API 审批、真实登录及正版启动仍未验收；自动认证测试使用模拟响应。

Windows x64 预发布版，保留现有实例与设置。微软 API 尚未获批，真实登录、刷新及正版启动仍待验收；第三方账号需单独进行真实服务验证。脱敏不能保证识别任意内容，游戏及模组原始日志和进程参数可能含个人信息。系统加密无法抵御以同一 Windows 用户身份运行的恶意软件。安装器未进行代码签名，校验和不等于发布者签名。

## AMBER beta 1.4 · 1.0.0-beta.5

Windows x64 本地测试版。本次仅交付本地安装包，尚未上传 GitHub。Microsoft Minecraft Services API 申请再次被拒，项目尚未获准；微软真实登录、刷新和正版启动继续延期验收，不推断拒绝原因。

### 实例工作区与收藏

- 实例管理分为“概览与检查、内容、启动设置、备份与恢复”，当前实例与版本始终明确；继续安装、准备 Java、修复游戏和管理账号有直接入口。
- 收藏实例始终置顶；支持最近创建、最近启动、名称和游戏版本排序，列表、侧栏及顶部切换顺序一致，收藏与排序跨重启保存。
- 保存最近启动记录，界面展示最近 20 次。记录仅表示进程已创建，不代表进入游戏或正常退出；不会补造旧版历史，移除实例的记录不提供启动按钮。

### 本地模组导入与内容恢复

- 每批选择最多 50 个 JAR / LiteMod 文件，读取基本名称、版本和加载器声明；检查相同文件、同名目标、重复模组标识及明确不兼容项，保留原始文件。
- 可选择通过精确文件哈希匹配 Modrinth 来源，只发送哈希、不上传文件。无法匹配或网络失败时按手动模组管理，不猜测更新来源。
- 导入前勾选文件并预览；可先停用导入，补齐已知依赖后启用。单文件上限 150 MB、每批 500 MB；复杂版本范围及未声明冲突不能完整识别。
- 安装、导入、更新、单项与批量启停 / 移除使用统一的变化预览。“内容 → 操作记录与恢复”集中显示新操作及旧版已有记录，执行前重新验证文件与清单。
- 中断或取消保留事务保护；恢复不会覆盖外部修改，也不回退存档和配置。缺失文件的残留记录可在预览与依赖检查后移除。

### 选择列表、检查与反馈

- 选择列表增加分组、读取中、读取失败及重试状态、清空搜索、长文字换行，改进输入法和键盘操作；继续适配深浅主题、直角 / 圆角与窄窗口。
- 实例检查核对安装收据和游戏文件、Java 版本、已知内容依赖、未完成计划和账号选择，给出对应解决入口；检查不尝试在线登录。
- 统一任务阶段及阻塞提示。取消后先等待文件整理完成，期间仍保护实例；错误详情支持复制，批量失败项目保留选择以便重新预览。
- 减少实例内容页重复导航，导入 / 恢复预览自动进入视野并明确目标实例，启动设置读取失败可重试。

程序安装目录与游戏数据目录保持分离，旧数据不自动迁移或删除。安装包未签名，使用同目录 SHA256SUMS.txt 核对。测试路径与实际验收边界见 prototype/BETA14-TESTING.md。

## AMBER beta 1.3 · 1.0.0-beta.4

Windows x64 预发布测试版。微软真实登录、刷新及正版启动继续等待审核后验收。

### 统一选择列表

- 实例、账号、组件发行版、内容筛选、备份与设置统一使用 AMBER 选择控件，支持浅色 / 深色、直角 / 圆角、信息密度和文字大小。
- 长列表内置关键词搜索、当前项定位、空结果提示；支持方向键、Home / End、Enter、Esc 和 Tab。
- 列表自动选择向上或向下展开，限制在窗口内；在创建弹窗中也不会被滚动区域裁切。禁用项保留原因，切换实例列表显示图标与版本说明。
- 选择后恢复键盘焦点；定位当前选项只滚动列表本身，不牵动后面的页面。

### 实例、商城与设置

- 每个实例独立保存启动账号和内存，可选择继承全局默认；默认账号、默认内存在“设置 → 游戏启动”管理。原账号移除后提示重新选择，不自动降级为离线身份。
- 在当前会话中保留商城关键词、分类、排序、页码和浏览位置；返回项目列表或离开再进入时恢复。不同实例及不同版本 / 加载器的浏览状态分开保存，安装预览不复用。
- 设置按外观与背景、游戏启动、下载、自定义布局、数据与引导分组，支持关键词查找和仅恢复当前组默认值。数据位置不提供自动重置。
- 任务中心将未完成安装及其阶段记录合并展示，保留明确的继续 / 修复 / 取消入口，增加已完成筛选与批量操作结果。

### 模组批量管理

- 支持逐项选择、全选当前筛选结果、清除选择，以及批量启用 / 停用 / 移除；明确提示包含隐藏选择，每批最多 200 项。
- 执行前展示影响清单，按最终启用集合检查已知依赖与作者声明的冲突；可把依赖和使用它的模组一起停用，保留用户已明确跳过的必需依赖例外。
- 执行前校验文件与预览状态，保留恢复副本与事务记录；中途失败 / 取消时尝试回滚，不覆盖外部修改或同名文件。游戏或其他任务运行时禁止执行。
- 显示每项结果。完成后可在“模组更新与恢复 → 刷新恢复记录”恢复操作之前的文件；仅在清单未发生后续变化时可直接恢复，不还原存档与配置。

手动导入且没有来源信息的模组无法完整检查依赖；作者未声明的运行冲突仍需实际游戏验证。安装包未签名，使用同目录 SHA256SUMS.txt 核对。测试路径与边界见 prototype/BETA13-TESTING.md。

### 登录与程序升级

- 点击微软登录，取得有效验证代码后自动复制一次并打开微软验证页面；保留再次复制、打开页面、取消、有效期和失败时手动操作入口。

- 在实例的已安装内容中检查当前游戏版本、加载器兼容的 Modrinth 模组更新，逐项选择；默认仅正式模组版本，可包含测试版。

- 更新中断后依据本地事务记录恢复；清单变化、同名文件、外部修改或校验失败时拒绝覆盖，并显示处理原因。

## AMBER beta 1.0 · 1.0.0-beta.1

AMBER 首个 beta 测试版，面向 Windows x64。此条目包含 beta 1.0 的全部交付内容及发布前依赖选择调整，共享同一版本号与更新日志。

### 游戏与实例

- Minecraft Java 版完整下载、并发校验、Java 检测与自动准备、原版启动和实例隔离。
- Fabric、Forge、NeoForge、LiteLoader、OptiFine 安装及已支持的历史组合；创建时自动禁用不兼容选项。
- 默认实例名、方块/工具图标、重命名、回收恢复及完整名称确认后的彻底删除。
- 安装计划跨重启继续；任务中心展示阶段、取消、重试及旧记录修复入口。
- 完整实例/存档与配置备份，校验后恢复为新实例；首次使用引导和数据目录复制校验迁移，旧目录保留。

### 模组与内容

- Modrinth 自动兼容搜索、分类与排序、项目图标和原站入口；模组、资源包、光影和 MRPACK 安装，本地地图 ZIP 导入。
- **必需依赖默认勾选，可取消；可选依赖默认不勾选，可自由选择。** 每项显示所属模组，取消必需项会提醒可能无法启动。
- 手动跳过仅作用于对应模组版本，随安装记录保存并支持重启续装；启动器不会仅因这条已明确跳过的依赖而阻止启动。加载器自身仍可能要求该依赖。
- 取消勾选不会删除已安装文件。同一项目仍被其他已勾选依赖需要时，会保留在下载清单中；未被跳过的依赖保护与已声明冲突检查继续生效。
- 模组启停与移除、跨版本清单导入导出、兼容版本重新匹配及跳过结果报告。

### 界面与账号

- AMBER 品牌及可复用字体，主题、直角/圆角、布局、字号、动画和背景设置。
- 启动面板与背景按钮支持 60–100% 不透明度；普通 UI 避免误选文字，输入、日志和错误仍可复制。
- 离线账号、可配置第三方 Yggdrasil 认证与微软设备码流程；项目公开 Client ID 内置，普通用户不需要注册 Azure 应用。
- MPL-2.0 源码、第三方许可文本和关于页 POP 倡议标识。

### 安装与升级

下载 `AMBER-1.0.0-beta.1-win-x64.zip`，解压完整目录后运行 `AMBER.exe`，不要单独移动 EXE。升级时关闭旧版启动器，解压到新的程序文件夹；默认沿用 `%APPDATA%/AMBER` 下的现有数据与数据位置配置。建议先备份重要世界。

源码位于 `AMBER-1.0.0-beta.1-github-source.zip`。Windows x64、Node.js 24、pnpm 11.25.0 下，在 `prototype` 中运行 `pnpm install --frozen-lockfile`、`pnpm test`、`pnpm build` 和 `pnpm package:desktop`。资源完整性可用随附 `SHA256SUMS.txt` 核对。

### 已知限制与测试边界

- **微软 Minecraft Services 审核和真实账号登录、刷新、启动尚待验收**；出现服务端拒绝不代表用户需要自己申请应用。第三方账号仍需目标服务实测。
- 当前为未签名的 Windows x64 便携测试包；其他系统、自动更新和 3D 场景交互未交付。
- 依赖是否需要以模组说明为准，不能凭名称判断。例如 Forge Config API Port 也面向 Fabric。取消真正必需的依赖可能导致加载失败。[作者项目说明](https://github.com/Fuzss/forge-config-api-port)
- Modrinth 元数据不能发现所有冲突，手动导入模组和任意历史组合不保证完整诊断。MRPACK 的可选客户端文件仍按既有规则跳过，与模组依赖勾选不是同一功能。
- 续装复用完整已校验文件，不提供单文件分段续传。同盘备份不防硬盘损坏；恢复后仍需准备 Java 并校验游戏。
- 自动化与桌面启动验证范围见 `prototype/VALIDATION.md`；不代表已完成所有游戏版本、长时间游玩、干净机器或断电场景验收。
