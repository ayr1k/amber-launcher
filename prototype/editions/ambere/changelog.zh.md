## 1.0.0

- Windows x64 正式版，AMBER 与 AmberE 保持独立安装、数据位置和更新仓库。
- 提供稳定与预览更新通道，从 Beta 升级时保留明确设置的通道偏好。
- 升级配置备份包含更新通道与窗口位置；数据目录重连拒绝父目录链接，失败时保留原位置。
- 提供实例备份、试用副本、变更记录与恢复，保护已有存档和配置。
- 统一版本号及主要功能展示，提供简体中文与英文界面。

升级前请关闭启动器和 Minecraft，并备份重要实例，然后覆盖安装对应产品。安装保留游戏数据。安装包未签名，备份和回退操作详见使用指南。

## Beta 1.14 — 预发布（1.0.0-beta.15）

- 增加稳定版与测试版更新通道，重启保留；切换不自动降级，Beta 可升级正式 1.0。
- 初始化前检查已配置的游戏库。磁盘断开或目录丢失时可重试、定位原库，不静默创建替代空库。
- 按需扫描主要存储分类，限制扫描规模并拒绝链接；清理前显示位置与大小，增加升级前备份入口。不自动清理实例或共享游戏文件。
- 支持单独校验备份，恢复仍创建独立实例。诊断导出使用已预览快照；分享错误时脱敏登录用户验证码。
- 在线账号在启动时刷新，不将离线资格缓存过期直接视为不可恢复错误；任务错误提供重试与对应实例/账号入口。
- 优化下拉框键盘焦点、存储和备份操作布局、更新说明换行及焦点可见性。
- AMBER 与 AmberE 同步适用改动，保留独立认证和更新规则；AmberX 未改动。

## Beta 1.13 — 预发布（1.0.0-beta.14）


- 重复登录复用有效请求；取消、过期、成功和失败时清理临时设备凭据。
- 区分认证服务/网络异常与游戏资格问题，提供重试和账号处理入口。
- 认证前检查实例运行状态，包含重启启动器后恢复的游戏进程。已移除账号不会静默替换。
- 账号移除确认、启动状态提示、响应式账号操作与中英文恢复提示。
- README 增加 AMBER、AmberE、AmberX 入口。AmberE 同步适用修复，保留独立认证与更新渠道；AmberX 未改动。

## Beta 1.12 — 1.0.0-beta.13（预发布）

- AMBER 与 AmberE 同步更新，保持独立认证、数据和更新来源。
- 保留 Beta 1.11 已测试安装包、源码及本次改动前工作区快照和 SHA-256 校验，供回滚使用；降级程序不会撤销游戏内进度。
