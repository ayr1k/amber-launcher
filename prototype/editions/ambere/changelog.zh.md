# 更新日志

[English](../../CHANGELOG.md)

## Beta 1.9 — 1.0.0-beta.10（预发布）

- 新增引导创建：问卷草稿、本地硬件信息、可解释且可修改的推荐方案；保留手动创建，新增直接按 Modrinth 整合包创建。
- 先满足服务器版本与加载器、必装项目、客户端环境、依赖、声明冲突、光影支持和资源预算，再对整套配置排序。
- 必要依赖默认勾选，允许明确取消并确认风险；支持可选依赖与移除推荐内容，修改后重新检查整体组合。
- 固定文件版本、哈希与大小，支持取消后及跨重启恢复；区分模组、材质、光影阶段，允许明确跳过剩余视觉资源。
- 实例概览保留创建方案与理由；建议实例内存，支持中英双语、主题与键盘操作。

推荐基于维护规则和实时元数据，不代表实际游戏测试。视觉包仅下载，需要在游戏内启用。安装器未签名，随预发布提供 Windows 安装包、源码包和 SHA-256 校验文件；微软真实登录仍待审批后验收。

## Beta 1.8 — 1.0.0-beta.9（预发布）

- AmberE 首次作为独立项目发布，基于 AMBER Beta 1.8 共用核心维护。版本编号跟随核心，不表示此前已有独立 AmberE Release。
- 使用已确认的金色标志，独立 Windows 应用身份、安装包、快捷方式和用户数据目录。
- 仅提供离线和第三方账号，移除微软登录控件及暴露接口，不内置微软 Client ID。保留实例安装、模组管理、恢复、显卡偏好等共用功能。
- 自动更新、Release 链接与安装包来源验证仅指向 `ayr1k/AmberE`，拒绝跨仓库或其他产品安装包。
- 中英引导、设置及账号页与实际能力一致；品牌替换不会改写用户名称或路径。

附 Windows x64 安装包、源码包与 SHA-256 校验文件。安装器未签名。本地测试用户需手动安装本次发布包一次，以切换此前测试包的更新地址。离线账号不授予 Minecraft 所有权；第三方真实服务需按具体提供方验收。AmberE 不提供微软登录，也不宣称获得微软 API 批准。
