# 更新日志

[English](../../CHANGELOG.md)

## Beta 1.12 — 1.0.0-beta.13（预发布）

- 优化模组更新布局与复选框对齐，放大并对齐快捷搜索与引导弹窗关闭图标。
- 新增实例工作台，区分安装状态、文件检查与用户实际游玩确认，集中处理入口和安装后指引。
- 新增独立试用副本，创建前检查磁盘空间，存档可选择独立复制。回写前预览差异：内容文件与清单成组应用，配置按文件选择，原实例变化时阻止覆盖；不合并存档进度或账号选择。
- 统一记录内容操作、启动与光影配置变化，保留校验过的恢复文件；检测外部修改，支持标记已确认可用状态及匹配当前文件的恢复操作。
- 中断事务在核对文件后恢复，遇到外部修改停止覆盖。将本地日志证据和近期变更关联展示，不将线索直接判定为崩溃原因。
- 扩展引导空间，下载与已安装内容采用列表和详情布局，保留浏览与导航位置，新增后台任务入口及 Ctrl+K 实例与操作搜索。
- 支持本地推荐偏好模板导入导出，严格验证格式，仅交换问卷偏好；应用模板后重新生成与检查方案。
- AMBER 与 AmberE 同步更新，保持独立认证、数据和更新来源。微软真实登录仍待审核通过后验收。本地安装包已通过用户测试，并获授权发布预发布 Release。
- 保留 Beta 1.11 已测试安装包、源码及本次改动前工作区快照和 SHA-256 校验，供回滚使用；降级程序不会撤销游戏内进度。

## Beta 1.11 — 1.0.0-beta.12（预发布）

- 统一弹窗、下拉列表和窗口控制栏的文本选择规则，保留输入、日志、路径与错误信息的复制能力。
- 引导问卷分组并折叠高级选项；优先展示档位差异，共同内容与完整清单按需展开。
- 推荐生成显示阶段并支持取消，区分网络、限流与兼容性问题。
- 分别自动保存新建及补装草稿；过期重新核验时保留偏好，展示文件清单变化。
- 新增本地偏好模板，使用时重新检查兼容性，删除需确认。
- 补装分组展示新增、已满足、保持停用与冲突，安装前重新检查实例变化。
- 两版同步增加安装后配置指引、内容与恢复入口；微软真实登录仍待审核后验收。

## Beta 1.10 — 1.0.0-beta.11（预发布）

- 深化引导创建：按功能寻找兼容文件与同类替代，保留指定模组、版本和加载器约束。
- 新增激进、综合、保守三档推荐，分别展示原版改动和额外资源负担，综合为默认。
- 扩展便利、性能、显示与明确选用的玩法主题目录；方案展示替代理由、排除原因和使用提示。
- 光影与远景按具体文件组合核验；使用作者画质预设，未知硬件保守处理，不覆盖已有配置。
- 新增实例补装推荐，保持已有版本、停用状态、配置和存档，支持事务恢复和任务续传。
- 推荐详情分类展示、自动重新检查、保留实例名称；同步中英文本与语言包模板。
- 微软真实登录仍待审批后验收；本版不宣称已完成游戏组合或显卡实测。

## Beta 1.9 — 1.0.0-beta.10（预发布）

- 新增引导创建：问卷草稿、本地硬件信息、可解释且可修改的推荐方案；保留手动创建，新增直接按 Modrinth 整合包创建。
- 先满足服务器版本与加载器、必装项目、客户端环境、依赖、声明冲突、光影支持和资源预算，再对整套配置排序。
- 必要依赖默认勾选，允许明确取消并确认风险；支持可选依赖与移除推荐内容，修改后重新检查整体组合。
- 固定文件版本、哈希与大小，支持取消后及跨重启恢复；区分模组、材质、光影阶段，允许明确跳过剩余视觉资源。
- 实例概览保留创建方案与理由；建议实例内存，支持中英双语、主题与键盘操作。

推荐基于维护规则和实时元数据，不代表实际游戏测试。视觉包仅下载，需要在游戏内启用。安装器未签名，随预发布提供 Windows 安装包、源码包和 SHA-256 校验文件；微软真实登录仍待审批后验收。

## Beta 1.8 — 1.0.0-beta.9（预发布）

- AmberE 首次作为独立项目发布，基于 AMBER Beta 1.8 共用核心维护。版本编号跟随核心，不表示此前已有独立 AmberE Release。
- 使用已确认的金色标志，独立 Windows 应用身份、安装包、快捷方式和用户数据目录。
- 仅提供离线和第三方账号，移除微软登录控件及暴露接口，不内置微软 Client ID。保留实例安装、模组管理、恢复、显卡偏好等共用功能。
- 自动更新、Release 链接与安装包来源验证仅指向 `ayr1k/AmberE`，拒绝跨仓库或其他产品安装包。
- 中英引导、设置及账号页与实际能力一致；品牌替换不会改写用户名称或路径。

附 Windows x64 安装包、源码包与 SHA-256 校验文件。安装器未签名。本地测试用户需手动安装本次发布包一次，以切换此前测试包的更新地址。离线账号不授予 Minecraft 所有权；第三方真实服务需按具体提供方验收。AmberE 不提供微软登录，也不宣称获得微软 API 批准。
