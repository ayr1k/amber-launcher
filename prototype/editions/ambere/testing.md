# Beta 1.11 / 验证说明

版本：1.0.0-beta.12。AmberE Windows x64 预发布版。用户已验收本地安装包并授权发布，安装包未签名。

- 弹窗、窗口控制栏、下拉菜单与界面标签禁止拖选；输入框、日志、错误和路径保留复制能力。
- 引导问卷分组，高级选项折叠；推荐先比较档位差异，共同内容和完整清单可展开查看。
- 生成过程显示实际检查阶段，可取消。网络失败和限流不再被当作模组不兼容。
- 新建与各实例补装分别保存草稿；过期方案需重新检查，保留偏好并展示与上次文件清单的差异。不同版本的依赖选择需再次确认。
- 本地模板只保存需求与偏好，使用时重新查找兼容版本，不包含账号、路径或安装文件。
- 补装分组展示新增、已满足、保持停用和冲突；安装前复查实例变化，保留版本、配置和存档。
- 安装后与实例概览提供配置指引、已安装内容、恢复记录和实例文件夹入口。

微软真实登录、刷新和正版启动仍待审核通过后验收。兼容信息核对不等于所有模组组合或显卡上的游戏实测，不承诺帧率。

已通过 231 项核心回归、4 项构建兼容测试和 1,786 条双语文本检查。两版桌面实测覆盖拖选禁止、输入框全选、模板保存、分组布局、自动保存、取消后重试、过期重检、小窗口中英显示、补装分类和恢复记录入口。未进行真实微软登录或新增游戏组合的运行验收。

## English

Beta 1.11 (1.0.0-beta.12) is a Windows x64 prerelease for AmberE. The user accepted both local installers and authorized publication; installers are unsigned.

App chrome, dialogs and popovers do not select text on dragging. Inputs, logs, errors and paths remain copyable. Guided forms group advanced settings and prioritize tier differences. Generation is cancellable and distinguishes network errors and rate limits from incompatibility. Separate creation/addition drafts retain preferences; expired plans require a new review with a file-change summary. Local templates store preferences only and resolve compatible content again on use. Addition previews preserve installed/disabled content, versions, configuration and worlds. Post-install guidance provides content, history and folder entry points.

Microsoft live acceptance remains deferred pending approval. Metadata checks are not gameplay or hardware certification.

Validation: 231 core tests, 4 build-compatibility tests and 1,786 bilingual entries passed. Both desktop editions passed selection/editing, template persistence, draft recovery, generation cancellation/retry, expiry recheck, small-window bilingual layouts, addition grouping and history entry checks. No live Microsoft authentication or additional gameplay-combination acceptance was performed.
