# AMBER beta 1.2 测试说明

版本：1.0.0-beta.3（界面称 Beta 1.2），以 GitHub 预发布方式提供。

## 安装

运行 `AMBER-1.0.0-beta.3-Setup-x64.exe`。升级前退出 AMBER 与 Minecraft，可覆盖现有 AMBER 程序目录。不要安装到游戏数据目录。安装器沿用 beta 1.1 的目录检查、旧程序备份与保留用户数据的卸载策略。

安装包未签名，请核对同目录 `SHA256SUMS.txt`。微软登录仍等待审核通过后验收。

## 本次变化

- 修复创建实例时版本列表穿过分组边框、覆盖“再显示”和其他分组的问题。版本结果采用单一滚动区域，标题、搜索和底部操作保持可见。
- 修复安装完成弹窗左右紧贴边框的问题，补充关闭按钮，窄窗口下按钮可换行。
- 搜索自动显示匹配数量并支持清空；返回上一步保留关键词、分组展开状态、所选版本和组件。更换游戏版本时清除旧组件配置。
- 底部明确显示已选版本及版本类型；快照提示独立存档，远古版本提示兼容性限制。
- 安装前显示实例名称、Minecraft 与加载器版本摘要；目录未就绪时不能继续。
- 改进步骤标题焦点、关闭后的焦点恢复，以及键盘焦点轮廓。保留原生弹窗的键盘限制和安装期间 Esc 防误关。
- 首次引导分离标题、可滚动内容与底部操作；玩家名输入独立成行，明确格式要求；最后一步按钮分组、间距统一。
- 空实例首页的说明与创建按钮拉开间距。背景设置采用上下排列的标签与控件，图片选择按钮对齐，不透明度滑块使用主题色。

## 建议验收

1. 创建实例 → 展开正式版 → 连续滚动到底并点击“再显示”，检查后续分组无重叠；搜索框及下一步按钮不滚走。
2. 搜索 `1.21.4` → 下一步 → 选择 Fabric → 上一步，检查关键词、版本与组件保留；清空搜索后检查之前展开的分组。
3. 切换游戏版本，检查旧加载器选择已清空。选择快照或远古版本，检查提示与安装摘要。
4. 在深色 / 浅色、方角 / 圆角，以及最小桌面窗口下重复以上流程。
5. 安装完成后检查内容留白，分别验证“添加模组与内容”“前往启动”和关闭入口，确认当前实例正确。
6. 设置 → 重新查看入门引导，验证三个步骤在小窗口下的间距、滚动和按钮；填写无效玩家名时不能保存，仍可选择稍后添加。

自动界面验证使用明确标识的合成目录与完成状态，不下载或安装真实 Minecraft。既有后端回归覆盖下载、依赖、更新和数据保护；本次不宣称重新完成所有加载器组合或微软真实认证验收。
