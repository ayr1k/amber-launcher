# AMBER beta 1.1 本地测试

版本：1.0.0-beta.2（界面称 beta 1.1）。本版本已完成本地安装验证，以 GitHub 预发布方式交付。

## 安装和升级

运行 `AMBER-1.0.0-beta.2-Setup-x64.exe`，选择独立的程序目录。默认按当前用户安装；创建开始菜单快捷方式，可选创建桌面快捷方式，不需要全机安装。安装器是完整程序包，首次安装不需要另外下载 Electron；Minecraft、Java 和模组仍按需联网获取。

安装前退出 AMBER 和 Minecraft。程序目录必须为空或为可识别的 AMBER 程序目录，不能与游戏数据目录重叠。需要至少 1.5 GB 程序盘空间及足够空间备份旧程序。升级前会校验复制旧程序；副本位置记录在 `%LOCALAPPDATA%\AMBER\previous-program.txt`。安装中断后可打开该副本运行旧版本或重新运行安装器。此机制不保证断电或磁盘损坏情况下自动恢复。

beta 1.0 便携版用户：将新版安装到新的程序目录，原便携文件夹保留。新版沿用 `%APPDATA%\AMBER` 中的数据位置配置。不要把安装目录选成游戏库。卸载只删除安装目录与快捷方式，保留账号、设置、实例、存档及程序备份。

当前安装包未签名。若系统提示发布者未知，请先核对交付位置和 SHA-256；本地测试版不宣称通过微软签名认证。

## 验证流程

1. 安装后启动，核对原有实例、账号和数据位置。再次打开快捷方式应回到同一窗口。
2. 账号 → 微软登录：取得代码后自动复制并打开微软页面；检查提示、再次复制、取消、过期和重新获取。复制失败仍可手动复制。微软 AppID 重新申请已提交、尚未获批，真实账号登录/刷新/正版启动本次不验收。
3. 关于 AMBER → AMBER 更新：检查公开 GitHub Release，展示说明，只接受 AMBER 仓库的 x64 安装包及有效 SHA-256。已安装 beta 1.1 且没有更高版本时，显示无更新是正常结果。未来有较新安装包时，可下载、取消、重试及校验后确认退出安装；运行游戏或任务时禁止升级。
4. 实例 → 已安装内容 → 模组更新：检查兼容更新，选择更新项，可锁定版本；默认只看正式模组版本，可自行包含测试版。必需依赖默认勾选、可取消，可选依赖默认不选。涉及多个模组的固定版本依赖冲突会阻止替换。
5. 更新完成后刷新恢复记录，再恢复更新前的文件。启停状态保留，存档和配置不随模组回退。更新后若清单或文件被更改，会拒绝直接覆盖。手动添加且未识别来源的模组不参与更新。
6. 在测试实例中验证取消下载、断网重试、游戏运行时禁止修改、同名文件保护。更新中断后下次启动会根据记录恢复旧文件；若发现外部修改会保留文件并报错。

## 本次范围

安装器、登录验证码复制、单实例行为、应用更新入口与升级保护、模组更新/锁定/恢复。未增加 3D 场景、多平台、自动后台安装、CurseForge 接入或旧启动器目录导入。

自动化验证采用合成实例与本地响应，不等同于所有模组组合、微软真实登录、真实断电或干净 Windows 机器验收。发布前仍需实际机器试用。

发布的安装包与本地验收包逐字节一致。安装包内“本地测试版”字样及随包文档记录构建时的状态；GitHub 的发布说明与本文件反映公开预发布状态。
