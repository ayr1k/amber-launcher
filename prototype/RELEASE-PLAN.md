# AMBER：三次更新交付计划

用户确认：从 alpha.2 基础开始，以接下来的三次更新覆盖原始需求。第 3 / 3 次更新已交付 alpha.5，当前已推进至 alpha.10，准备 beta 1.0 的源码和发布验收。计划不等同于所有功能已验收；外部账号和历史版本兼容性单独记录。

## 第一次：alpha.3 — 账号与 Fabric（已交付）

- 原版完整下载、Java 管理、隔离、并发校验安装继续复用。
- 真实实例库成为桌面主界面；浏览器设计原型保持独立。
- 保存离线账号；微软公开 Client ID 配置、设备码、Xbox / Minecraft 所有权与角色检查、刷新；第三方 HTTPS Yggdrasil API 登录、角色切换、刷新和 authlib-injector 启动桥接。
- Windows safeStorage 加密凭据，不保存密码、不向渲染器返回令牌、认证失败不降级离线。
- Fabric 官方兼容版本查询、稳定版优先、官方 Maven 依赖哈希、安装收据、启动与切回原版。
- 验收：自动化账号契约与故障测试；真实 Minecraft 1.21.1 + Fabric 0.19.5 + Java 21 完成图形和音频初始化。
- 未完成实测：微软真实账号（项目应用已注册并内置 Client ID，API 访问申请待审核）；真实第三方账号与皮肤/联机认证。下一次更新继续保留此验收项，不视为已通过。

## 第二次：加载器与内容商城

- Forge / NeoForge 安装处理器与依赖校验；LiteLoader 历史版本适配；OptiFine 合规下载或导入安装、组合兼容性矩阵。不可组合的加载器明确禁选，不承诺任意组合。
- 在新版本安装流程内统一选择加载器与可选组件。
- 接入 Modrinth（满足原要求 CurseForge 或 Modrinth 二选一），浏览/搜索、按 MC 与加载器筛选版本。
- 模组、光影、材质包、整合包、地图：下载校验、类型路由、受控解包；平台没有对应分类或项目时提供清晰的导入路径，不伪造搜索结果。
- 模组依赖图、冲突与可选依赖预览、一键安装必需依赖；真实启用/停用、清单持久化、运行中保护。
- 整合包为独立实例，避免覆盖已有存档；服务端限制和许可条件明确呈现。
- 验收：真实模组带依赖安装与启动；各加载器至少一个受支持版本；取消/失败不形成可启动的半成品。

## 第三次：迁移、个性化与完整验收

- 真实清单导入导出：稳定项目 ID、来源、版本与启停状态；目标 MC/加载器重新解析，跳过无兼容版本，依赖联动与最终持久化报告；源实例不变。
- 外观、密度、布局、启动行为、横幅等设置落到桌面；字体与许可随包可复用。
- 对照用户 POP 文档复核：可导出数据、可替换内容/认证提供者、分层扩展接口与能力说明。已有场景动作接口保留；3D 渲染器及用户自建场景按此前决定延后。
- 下载恢复、异常退出、版本兼容矩阵、安装/启动错误可诊断、授权与依赖许可审计、回归验收。
- 记录仍需用户应用注册、真实账号、平台分发许可等外部条件。不能用模拟界面替代验收。

## 边界

本阶段目标平台为 Windows x64。macOS/Linux、代码签名、自动更新服务不是本轮原始需求的验收前提。当前便携目录包未签名。并发下载为多个文件并行，已经满足多线程下载目标；单文件分段续传是后续增强。任何缺少官方元数据或不支持的历史组合均显式报错。

## Alpha.4 实际交付及第三次更新补齐项

已交付官方 Forge / NeoForge 安装器与补丁校验、LiteLoader release 适配、OptiFine 独立安装与 Forge 模组导入；Modrinth 模组/光影/资源包搜索安装、递归依赖与冲突预览、内容开关与回收、MRPACK 客户端安装、本地地图 ZIP 导入、分阶段微软错误提示。代表版本的真实游戏启动已验证，详见 VALIDATION.md。

本次边界：加载器在创建实例后、安装游戏前配置；MRPACK 需先手动创建与配置精确版本的独立实例。Forge+LiteLoader / OptiFine+Forge 组合验收、26.x NeoForge 和旧 Forge 命令行兼容、自动创建整合包实例、强制退出事务恢复均保留为第三次更新的补齐项，不能视为已完成所有原始需求。地图由本地导入提供，不伪造 Modrinth 地图分类。微软审核仍是外部条件。

## Alpha.5 实际交付（第三次更新）

已完成统一创建弹窗与 Java→加载器→游戏→可选迁移流水线，加载器禁选与 Forge + OptiFine 组合，自动兼容搜索及 Modrinth 图标/外链，真实模组清单导入导出与逐项持久化报告，个性化设置，MRPACK 自动创建精确版本实例，内容事务日志及启动恢复。新增实测旧 Forge 1.12.2、新 NeoForge 26.1、Forge 52.0.16 + OptiFine J1、1.21.1→1.20.1 模组迁移，均通过渲染/音频初始化。

三次更新已交付主体，但不把原始全部设想标为全部完成。遗留：Forge + LiteLoader 等更多组合、所有历史版本矩阵、真实微软账号（审核待确认）及第三方账号、插件分层权限与信任治理、任意布局编辑器。3D 场景按用户要求延后。自定义目前是主题/密度/文字/动画/运行默认值；地图目前是本地 ZIP 导入。无损续传仅复用完整已校验文件，单文件分段续传未实现。恢复为启动时处理内容复制事务，不能承诺任意硬件故障下的跨文件系统原子性。


## alpha.6 — 交互与历史兼容性完善

已实现：分离启动首页和实例管理；两步组件创建；实例改名、回收、恢复；结构化自定义布局与导入导出；旧 Forge 安装接口、缺失客户端依赖、LiteLoader Ivy 发行版及 OptiFine 共存启动参数适配。历史组合实测见 VALIDATION.md。BakaXL 仅提供交互参考，没有复制其美术或代码。

微软登录真实端到端验收按用户要求延期，等待审核通过；本轮没有把待审核状态改成已通过。布局编辑范围是导航、宽度、列表视图及首页模块，不包含任意网页脚本或插件执行。

## alpha.7 — 全流程与外观细节

已实现可选圆角、实例图标及默认命名、配置返回保留、自动依赖预检、紧凑管理列表、依赖启停保护和旧安装预览失效检查。移除重复标题并补齐创建/安装后的导航。已用新的 1.21.4 Fabric 实例完成下载、Java、Mod Menu 及两项依赖安装和实际启动。微软账号真实验收按用户要求延期；完整历史版本与任意模组组合不因单个端到端测试而视为全部通过。

## alpha.8 — 异常恢复与背景

已实现：整条配置链取消、原实例会话内重试、网络失败退避、Modrinth 分类与排序、已知模组冲突的启用/启动前检查、崩溃原因建议与直达日志、最近异常记录持久化、预设及本地背景。保留原实例与已验证缓存。自定义图片通过本机文件选择器导入，复制并规范为受控 PNG 路径。

## alpha.10 — 持久恢复与数据管理

完整安装计划和独立 Modrinth 内容任务跨重启继续；可选依赖保存选择并递归校验；实例备份逐文件校验且恢复为新实例；首次引导及游戏数据目录迁移；启动面板不透明度和普通 UI 防误选。任务中心支持继续、取消、结束停止的内容任务，以及按当前配置修复旧版不完整记录。
