# AMBER · 1.0.0-beta.2

Windows x64 桌面开发版，第三次更新后的兼容性与交互完善版。项目自有源码采用 MPL-2.0。统一更新日志及 Release 正文见仓库根目录 CHANGELOG.md。

## beta 1.1

本地安装包：`releases/beta1.1/AMBER-1.0.0-beta.2-Setup-x64.exe`。新增验证码自动复制、程序更新入口与保护、模组兼容更新/锁定/恢复。安装与测试说明见 [BETA11-TESTING.md](BETA11-TESTING.md)。beta 1.1 以 GitHub 预发布版本提供；微软真实授权继续延后。

构建安装包：`pnpm package:installer`（Windows x64，使用 NSIS；不会发布）。

## beta 1.0

- **任务跨重启恢复**：创建实例、安装模组/整合包保留阶段、精确版本和可选依赖选择，重启后到“任务中心”明确继续。取消不会自动开始下一阶段。单文件未完成部分仍需重新下载，不是分段续传。
- **任务与实例状态**：区分等待继续、正在配置、需要处理和游戏运行中。停止的独立内容任务可以结束记录并保留已安装文件；旧版/损坏记录可按当前配置修复 Java 和游戏，无法找回的模组/整合包计划需要重新选择。
- **实例备份**：“实例 → 备份库”或实例内“备份与恢复”。支持完整实例内容、存档与配置；逐文件校验，始终恢复为新实例。备份库可找到原实例已移除的备份。共享 Java/游戏缓存不重复备份；恢复后到任务中心准备 Java 并校验游戏。存档模式不含模组，需补齐兼容模组才能打开相应世界。
- **数据位置与首次引导**：“设置 → 游戏数据位置”选择空目录，复制并校验后切换和重启，旧目录保留。首次运行依次引导位置、账号、创建实例；已有实例的用户不强制经过引导。游戏和下载运行时不能迁移。迁移失败不切换目录，目标残留副本保留供检查，下次请选择空文件夹。
- **依赖选择**：Modrinth 模组版本页的必需依赖默认勾选、可选依赖默认不勾选，均可调整；取消必需项会保存对此模组版本的例外，任务重启与启动预检不会擅自恢复。冲突检查和其他依赖保护保留。不适配的可选项显示原因。MRPACK 自身的可选客户端文件仍按原规则跳过，不冒充模组依赖选项。
- **外观与文字操作**：设置中调节启动面板/背景按钮不透明度 60–100%，默认 100%；无毛玻璃。拖动普通界面不会选中文字，输入、日志和错误详情仍可选择复制。

备份保存在所选数据目录的 `backups/` 中；同盘备份不防磁盘损坏。备份/迁移取消或校验失败的临时副本不会列为成功备份，也不会自动删除原始数据。重要备份可另行复制到另一块磁盘。

微软真实授权仍等待审核。

## 运行与创建

运行本地 beta 1.1 安装包后，从 AMBER 快捷方式启动。默认数据位置为 `%APPDATA%/AMBER/library`（可在设置中迁移），沿用既有实例、Java、缓存和加密账号库。便携测试包未签名；本地交付包已准备，尚未执行公开上传。

点击“实例 → 创建实例” → 选择 Minecraft 版本 → 下一步逐项配置组件 → “创建并安装”。AMBER 自动准备匹配的 Java、安装加载器并下载完整游戏；完成后选择账号启动。游戏版本输入即筛选；加载器目录自动按游戏版本查询，不支持的组合禁用。Forge 可附加官方 OptiFine JAR，需按 OptiFine 官网声明匹配 Forge 版本。历史 LaunchWrapper 版本可组合 Forge + LiteLoader、OptiFine + LiteLoader，以及三组件组合；根据实际官方发行版选择，不能保证任意 Forge / OptiFine 版本彼此兼容。独立 OptiFine 亦可选择，不分发其二进制文件。

创建失败会保留实例、缓存及 setup-report.json；可通过“实例 → 管理 → 版本设置与修复”继续准备 Java、配置加载器及修复游戏。不会把失败的配置报告为成功。

## alpha.7 — 创建、内容管理与启动流程打磨

- 设置增加“经典直角 / 柔和圆角”，即时生效并持久保存；旧设置默认直角。修复深色原生下拉选项的背景、文字和系统配色，并提高深色错误信息对比度。
- 创建时选择草方块、土方块、铁砧或铁镐图标；在实例列表可再次更换。新实例默认使用 `1.21.4-fabric` 等名称，组合组件顺序固定；保留自定义名称。返回上一步不重置所选发行版。
- 创建成功后直接选择“添加模组与内容 / 前往启动”。加载失败可重试；组件获取失败不会误显示为可安装。
- 模组选择后自动预检依赖；显示已安装、重新启用与新下载。支持按名称、文件、类型及启用状态筛选已安装内容，单行开关、Modrinth 项目链接和二次确认移除；移除文件仍可在实例 `content-trash` 中手动找回。
- 后端阻止停用或移除被已启用模组必需依赖的内容；启用时检查已记录依赖的启用和文件状态。已安装内容改变后旧预览失效。未固定版本的必需依赖优先复用已有兼容版本。
- 独立整合包搜索允许不同加载器；安装进当前实例时仍严格校验版本。迁移停用顺序按依赖关系处理，循环依赖保留启用并写入报告。
- 游戏运行或下载占用时显示操作限制原因；离线名称即时校验；异常退出提供日志入口。微软真实登录仍等待审核通过后验收。

验证：72 项功能/模型/文件系统测试和 4 项 Sites 测试通过；实际新建 1.21.4 + Fabric 0.19.5，自动安装 Mod Menu 13.0.4、Text Placeholder API 2.5.2+1.21.3、Fabric API 0.119.4+1.21.4，并启动到渲染、音频和模组初始化。详情见 `VALIDATION.md`。当前源码包可用 `node scripts/verify-update8.mjs` 重现类似流程（会创建新的专用实例、联网下载并短暂启动游戏）。

## alpha.6 交互与兼容性完善

- **启动首页**：集中显示实例、账号、玩家名称、内存和启动按钮；保存上次账号选择。模组、内容下载、跨版本迁移有直接入口。参考 HMCL / PCL / BakaXL 的操作层级，保留 AMBER 的森林绿、暖白、平面线条与字体。
- **实例管理**：列表／网格、即时搜索、打开目录、重命名、删除与恢复。删除将完整实例移至 `instance-trash`，保留存档、模组和配置；在回收站恢复。运行中的实例及未完成的安装任务会阻止修改。alpha.9 新增逐个彻底删除。
- **自定义布局**：左／右／顶部导航、侧栏宽度、内容宽度、首页模块拖动或按钮排序、显示／隐藏、三个布局预设，JSON 导入／导出。保存于 preferences.json，重启保留。仅配置布局字段，不执行导入文件中的 HTML 或脚本。
- **组件创建流程**：先选游戏，再勾选组件并选择各自发行版；互斥项禁用并说明原因。旧实例支持附加／移除 LiteLoader；移除时校验并恢复基础加载器配置，再安装修复。
- **历史兼容性**：兼容没有 `--installClient` 的旧 Forge 安装器，补齐客户端依赖；支持 LiteLoader Ivy / Maven 发布格式、稳定发行标识与 HTTPS 官方仓库；修复 OptiFine + LiteLoader 重复参数问题。已实测的版本与边界详见 VALIDATION.md。

## 第三次更新保留功能

- **跨版本迁移**：从“模组迁移”导出 AMBER JSON 清单，在新建时附加或迁入当前实例。记录 Modrinth 稳定项目 ID、源版本和启停状态；手动 JAR 通过 SHA-1 查询项目身份（仅发送哈希，不上传文件）。目标版本重新解析发行版和必需依赖，无兼容发行版、未知来源、缺失依赖及冲突逐项跳过。源实例不变；结果保存到 migration-report.json，并可在迁移页查看。源中关闭的模组保持关闭，若其他启用模组必需则保持启用并说明。
- **个性化**：浅色/深色/跟随系统，森林绿/琥珀/石板灰强调色，舒适/紧凑密度，文字大小，动画开关，默认内存和 1–16 并发文件数。存于 preferences.json；动画遵循系统减少动态效果设置。
- **商城操作**：输入后自动查找当前 MC / 加载器兼容内容，过期查询不覆盖新结果。显示 Modrinth 项目图标，点击图标或详情链接在外部浏览器打开对应项目。兼容发行版优先正式版，递归依赖与冲突预览继续可用。
- **整合包**：MRPACK 预览后可一键创建独立实例，自动按清单准备精确游戏、Java 和加载器版本，再安装包内容。现有实例仍可在版本精确匹配且无文件覆盖时安装。客户端 optional / unsupported 文件跳过并记录。
- **兼容性**：补齐 NeoForge 26.x 版本号映射、OptiFine 目标游戏版本检查；实测新增 Forge 1.12.2、NeoForge 26.1、Forge + OptiFine 和跨版本迁移启动。
- **中断恢复**：Modrinth / MRPACK 在复制前写事务日志，提交清单标记事务。重启将未提交且校验一致的文件移入 content-recovery；用户改过的文件保留并提示。配置流水线中断会标记 interrupted。共享下载缓存可在重试时校验复用，不是单文件分段续传。

## 账号及未完成验收

内置公开 Client ID `ab7cf49a-fea7-432d-8ce8-beb922eb554e`，普通用户直接点击微软登录；自定义应用在高级设置。微软 API 访问申请已提交，审核结果待确认，真实登录端到端验收尚未通过。错误提示区分微软、Xbox/XSTS、Minecraft 服务、所有权、角色读取、网络和限流，不把所有 HTTP 403 归因为审核。

第三方 HTTPS Yggdrasil、角色选择、刷新和 authlib-injector 已接入，但真实第三方账号仍待验收。Windows safeStorage 加密凭据，不保存密码，不向渲染器返回令牌；认证失败不降级为离线账号。

仍未完成：任意历史版本及任意模组组合的全集验收、第三方插件安装/权限/信任系统、自由 HTML/CSS 页面编辑器、3D 场景渲染。结构化布局编辑已实现。场景交互按用户决定保留适配接口并延后，不以界面样例冒充这些能力。CurseForge 非本轮必选项，已选择 Modrinth。
